SQL über das Sternschema

ClickHouse

Aggregationen über Millionen Zeilen. Die eingebaute Konsole liegt unter /play — kein weiteres Werkzeug nötig.

SELECT reporting_city,
       nibrs_family,
       count() AS n
FROM fact_offense
GROUP BY 1, 2
ORDER BY n DESC
LIMIT 10
