storage.backend

Die Ablage: lokal, SeaweedFS ueber S3, oder beides (hybrid).

Lesen im Hybridmodus: lokal zuerst, sonst S3. Schreiben: lokal, pruefen, dann publizieren. Kein Dual-Write, keine Synchronisation in beide Richtungen. Das lokale Verzeichnis ist Arbeitskopie und Cache; SeaweedFS ist der gemeinsame veroeffentlichte Bestand.

Geholt wird seit dem 17.9.2026, was unveraenderlich ist: Raw- und Bronze-Laeufe (hole_fehlende_laeufe) und Releases (storage.release). Silver und Gold werden weiterhin gelesen, nicht kopiert - ein stiller Cache waere eine zweite Wahrheit mit eigenem Alter.

Publizieren ist gezielt: die Dateien eines Laufs oder einer Tabelle, manifest.json zuletzt - so ist das Manifest auf S3 das Zeichen, dass ein Lauf vollstaendig oben ist, genau wie das Umbenennen lokal.

Zwei Sorten Ziele:

  • Unveraenderliche Laeufe (run_<id>): existiert ein Objekt schon und ist identisch, wird es uebersprungen; existiert es mit anderem Inhalt, ist das ein Fehler. Nichts wird still ueberschrieben.
  • Abgeleitete Tabellen (silver/dataset=..., gold/dataset=...): lokal werden sie ersetzt, nicht angehaeuft (siehe silver_pipeline). Auf S3 gilt dasselbe - sie werden ueberschrieben. Das Manifest nennt die Bronze-Laeufe, aus denen der Stand entstand.

Nach jedem Upload wird das Objekt zurueckgelesen: Existenz und Groesse immer, die MD5-Pruefsumme gegen das ETag, wo der Dienst eines liefert.

Der veraltete lokale Stand. Die Regel "lokal zuerst" hat eine scharfe Kante: Wer eine Silver- oder Gold-Tabelle von letzter Woche herumliegen hat, liest sie - auch wenn auf SeaweedFS eine neuere liegt, und ohne es zu merken. Und veroeffentlicht er sie, verdraengt sein alter Stand den neuen. Deshalb vergleicht die Ablage bei abgeleiteten Tabellen beide Manifeste:

  • Beim Lesen eine Warnung, wenn die lokale aelter ist - gelesen wird trotzdem lokal, denn das ist die Regel.
  • Beim Publizieren eine Absage, wenn der eigene Stand aelter ist oder auf weniger Bronze-Laeufen ruht. Wer wirklich zurueckdrehen will, sagt erzwingen=True.

Verglichen wird built_at_utc (tragen alle neun Tabellen) und die Lauf-Kennungen aus derived_from. Gold nennt dort Silver-Tabellen statt Laeufe; fuer Gold zaehlt deshalb nur der Zeitpunkt.

106# Vor dem ersten Nachpublizieren antwortete SeaweedFS auf ein HEAD einmal mit
107# 403 - und Sekunden spaeter auf denselben Schluessel mit 404. Solche Aussetzer
108# (403, 5xx, Verbindungsabbruch) werden ein paarmal mit Pause wiederholt, bevor
109# sie ein Fehler sind. boto3 wiederholt 403 von sich aus nicht.
110VERSUCHE = 4
111PAUSEN = (1.0, 3.0, 8.0)
112VORUEBERGEHEND = {"403", "AccessDenied", "500", "502", "503", "504",
113                  "InternalError", "ServiceUnavailable", "SlowDown", "RequestTimeout"}

116class Boto3Client:
117    """S3 ueber boto3, path-style, gegen den konfigurierten Endpoint."""
118
119    def __init__(self, config: Config) -> None:
120        import boto3
121        from botocore.config import Config as BotoConfig
122
123        self.bucket = config.s3_bucket
124        self.endpoint_url = config.endpoint_url
125        self._client = boto3.client(
126            "s3",
127            endpoint_url=config.endpoint_url,
128            aws_access_key_id=config.s3_access_key,
129            aws_secret_access_key=config.s3_secret_key,
130            region_name="us-east-1",
131            config=BotoConfig(
132                s3={"addressing_style": "path"}, signature_version="s3v4",
133                retries={"max_attempts": 4, "mode": "standard"},
134            ),
135        )
136
137    def _mit_wiederholung(self, was: str, aufruf):
138        """Fuehrt ``aufruf()`` aus; voruebergehende Fehler werden wiederholt."""
139        from botocore.exceptions import BotoCoreError, ClientError
140
141        for versuch in range(VERSUCHE):
142            try:
143                return aufruf()
144            except ClientError as fehler:
145                code = str(fehler.response.get("Error", {}).get("Code", ""))
146                if code in ("404", "NoSuchKey", "NotFound"):
147                    raise
148                letzter = fehler
149                if code not in VORUEBERGEHEND:
150                    break
151            except BotoCoreError as fehler:
152                letzter = fehler
153            if versuch < VERSUCHE - 1:
154                LOG.warning("SeaweedFS: %s bei %s - Versuch %d von %d, Pause %.0f s",
155                            type(letzter).__name__, was, versuch + 1, VERSUCHE, PAUSEN[versuch])
156                time.sleep(PAUSEN[versuch])
157        raise self._uebersetzt(letzter, was) from letzter
158
159    def _uebersetzt(self, fehler: Exception, was: str) -> StorageError:
160        """Ein boto-Fehler als ein Satz - Endpoint und Ursache, keine Schluessel."""
161        from botocore.exceptions import ClientError, EndpointConnectionError
162
163        if isinstance(fehler, EndpointConnectionError):
164            return StorageError(
165                f"SeaweedFS nicht erreichbar: {self.endpoint_url} ({was}). "
166                "Stimmt S3_ENDPOINT, und loest der Hostname auf? "
167                "'python -m storage' prueft die Verbindung."
168            )
169        if isinstance(fehler, ClientError):
170            code = str(fehler.response.get("Error", {}).get("Code", "?"))
171            return StorageError(
172                f"SeaweedFS lehnt ab: {code} bei {was} auf {self.endpoint_url}, "
173                f"Bucket {self.bucket!r}. Bei AccessDenied/InvalidAccessKeyId/"
174                "SignatureDoesNotMatch die Schluessel pruefen, bei NoSuchBucket den Bucket."
175            )
176        return StorageError(f"SeaweedFS: {type(fehler).__name__} bei {was}: {fehler}")
177
178    def head(self, key: str) -> Objekt | None:
179        from botocore.exceptions import ClientError
180
181        try:
182            antwort = self._mit_wiederholung(
183                f"HEAD {key}", lambda: self._client.head_object(Bucket=self.bucket, Key=key))
184        except ClientError as fehler:
185            code = str(fehler.response.get("Error", {}).get("Code", ""))
186            if code in ("404", "NoSuchKey", "NotFound"):
187                return None
188            raise self._uebersetzt(fehler, f"HEAD {key}") from fehler
189        return Objekt(key, int(antwort["ContentLength"]), antwort.get("ETag", ""))
190
191    def get(self, key: str) -> bytes:
192        from botocore.exceptions import ClientError
193
194        try:
195            return self._mit_wiederholung(
196                f"GET {key}",
197                lambda: self._client.get_object(Bucket=self.bucket, Key=key)["Body"].read())
198        except ClientError as fehler:
199            raise self._uebersetzt(fehler, f"GET {key}") from fehler
200
201    def put(self, key: str, daten: bytes) -> None:
202        self._mit_wiederholung(
203            f"PUT {key}",
204            lambda: self._client.put_object(Bucket=self.bucket, Key=key, Body=daten))
205
206    def list(self, prefix: str) -> list[Objekt]:
207        def alle() -> list[Objekt]:
208            gefunden: list[Objekt] = []
209            paginator = self._client.get_paginator("list_objects_v2")
210            for seite in paginator.paginate(Bucket=self.bucket, Prefix=prefix):
211                for eintrag in seite.get("Contents", []):
212                    gefunden.append(Objekt(eintrag["Key"], int(eintrag["Size"]),
213                                           eintrag.get("ETag", "")))
214            return gefunden
215
216        return self._mit_wiederholung(f"LIST {prefix}", alle)

243def zeitpunkt(manifest: dict[str, Any]) -> datetime | None:
244    """Wann diese Tabelle gebaut wurde. Alle neun tragen ``built_at_utc``."""
245    roh = manifest.get("built_at_utc") or manifest.get("completed_at_utc")
246    if not roh:
247        return None
248    try:
249        wann = datetime.fromisoformat(str(roh).replace("Z", "+00:00"))
250    except ValueError:
251        return None
252    return wann if wann.tzinfo else wann.replace(tzinfo=timezone.utc)

255def eingaben(manifest: dict[str, Any]) -> frozenset[str]:
256    """Die Bronze-Laufkennungen, auf denen eine Tabelle ruht.
257
258    Drei Formen, gewachsen und bewusst nicht angeglichen: ``crime_offense``
259    fuehrt Listen je Stadt (``chicago_bronze_runs``), die uebrigen
260    Silver-Tabellen eine Liste von Eintraegen mit ``run_id``, und Gold nennt
261    Silver-Tabellen statt Laeufe - dort bleibt die Menge leer, und es zaehlt
262    allein der Zeitpunkt.
263    """
264    herkunft = manifest.get("derived_from")
265    gefunden: set[str] = set()
266    if isinstance(herkunft, dict):
267        for schluessel, wert in herkunft.items():
268            if schluessel.endswith("_runs") and isinstance(wert, list):
269                gefunden.update(str(v) for v in wert)
270    elif isinstance(herkunft, list):
271        for eintrag in herkunft:
272            if isinstance(eintrag, dict) and eintrag.get("run_id"):
273                gefunden.add(str(eintrag["run_id"]))
274    return frozenset(gefunden)

277class Standvergleich(NamedTuple):
278    """Der eigene Stand einer abgeleiteten Tabelle gegen den auf SeaweedFS."""
279
280    tabelle: str
281    hier: datetime | None
282    dort: datetime | None
283    fehlende_eingaben: frozenset[str]
284
285    @property
286    def aelter(self) -> bool:
287        return self.hier is not None and self.dort is not None and self.hier < self.dort
288
289    @property
290    def veraltet(self) -> bool:
291        """Aelter gebaut, oder auf Laeufen, die hier gar nicht erreichbar sind.
292
293        ``fehlende_eingaben`` sind **nicht** einfach die Laeufe, die der Stand
294        oben nennt und der hiesige nicht - das waere zu streng. Siehe
295        ``Storage.vergleiche_stand``.
296        """
297        return self.aelter or bool(self.fehlende_eingaben)
298
299    def satz(self) -> str:
300        teile = []
301        if self.hier and self.dort:
302            teile.append(f"hier gebaut {self.hier:%d.%m.%Y %H:%M} UTC, "
303                         f"auf SeaweedFS {self.dort:%d.%m.%Y %H:%M} UTC")
304        if self.fehlende_eingaben:
305            namen = ", ".join(sorted(self.fehlende_eingaben)[:3])
306            mehr = "" if len(self.fehlende_eingaben) <= 3 else f" und {len(self.fehlende_eingaben) - 3} weitere"
307            teile.append(f"dort stecken {len(self.fehlende_eingaben)} Bronze-Lauf/Laeufe, "
308                         f"die hier fehlen ({namen}{mehr})")
309        return f"{self.tabelle}: " + "; ".join(teile)

356    def tabellenverzeichnis(self, rel: str) -> str:
357        """Das Verzeichnis, in dem das Manifest liegt - aus Datei oder Ordner."""
358        letzter = rel.rsplit("/", 1)[-1]
359        return rel.rsplit("/", 1)[0] if "." in letzter else rel

361    def entfernter_stand(self, verzeichnis: str, *, frisch: bool = False) -> dict[str, Any] | None:
362        """Das Manifest dieser Tabelle auf SeaweedFS, oder None."""
363        if not self.config.remote:
364            return None
365        if not frisch and verzeichnis in self._entfernte_manifeste:
366            return self._entfernte_manifeste[verzeichnis]
367        schluessel = f"{verzeichnis}/{MANIFEST}"
368        manifest = None
369        if self.client.head(schluessel) is not None:
370            try:
371                manifest = json.loads(self.client.get(schluessel).decode("utf-8"))
372            except (ValueError, UnicodeDecodeError):
373                LOG.warning("Manifest auf SeaweedFS nicht lesbar: %s", schluessel)
374        self._entfernte_manifeste[verzeichnis] = manifest
375        return manifest

377    def verfuegbare_laeufe(self, schicht: str = "bronze") -> frozenset[str]:
378        """Jede Laufkennung, die hier erreichbar ist - lokal oder auf S3.
379
380        Gelesen werden die Manifeste, nicht die Verzeichnisnamen: Detroit
381        nennt seine Kennung ``pipeline_run_id``, die uebrigen ``run_id``.
382        Einmal je Ablage ermittelt; ``hole_lauf`` verwirft den Zwischenstand,
383        weil danach mehr da ist.
384        """
385        if schicht not in self._verfuegbar:
386            self._verfuegbar[schicht] = frozenset(
387                lauf.run_id for lauf in self.laeufe(schicht, "**/manifest.json",
388                                                    streng=False)
389            )
390        return self._verfuegbar[schicht]
391
392    def vergleiche_stand(self, verzeichnis: str, lokal: dict[str, Any] | None = None, *,
393                         frisch: bool = False) -> Standvergleich | None:
394        """Vergleicht die lokale Tabelle mit der auf SeaweedFS.
395
396        ``None``, wenn nichts zu vergleichen ist: keine der beiden Seiten da,
397        oder eine Schicht, in der Staende einander nicht verdraengen.
398
399        **Was als fehlend zaehlt.** Bis zum 17.9.2026 galt jeder Lauf als
400        fehlend, den der Stand oben nennt und der hiesige nicht. Das war zu
401        streng, und es hat an diesem Abend einen Gesamtlauf abgebrochen:
402
403            silver/dataset=weather_day: hier gebaut 19:30 UTC, auf SeaweedFS
404            16:05 UTC; dort stecken 1 Bronze-Lauf/Laeufe, die hier fehlen
405            (run_20260908T201217784384Z)
406
407        Der hiesige Stand war **neuer** und ruhte auf einem **neueren**
408        NOAA-Lauf. NOAA liefert Vollschnappschuesse, und
409        ``build_weather_day`` nimmt deshalb nur den juengsten - der Lauf vom
410        8.9. war nicht verloren, sondern abgeloest. Er lag die ganze Zeit
411        unter ``data/bronze``.
412
413        Deshalb zaehlt jetzt, ob ein Lauf hier **erreichbar** ist, nicht ob
414        der Bau ihn benutzt hat. Die Absicht der Regel bleibt: Wer einen Lauf
415        geloescht oder nie geholt hat und daraus neu baut, verdraengt einen
416        reicheren Stand - und genau dann ist der Lauf auch nicht erreichbar.
417        Bei Chicagos Deltas aendert sich nichts: ``crime_offense`` liest alle
418        Laeufe, ein erreichbarer taucht dort immer auch in der Herkunft auf.
419        """
420        if verzeichnis.split("/")[0] not in ABGELEITET or not self.config.remote:
421            return None
422        if lokal is None:
423            pfad = self.local_path(verzeichnis, MANIFEST)
424            if not pfad.exists():
425                return None
426            manifest = read_manifest(pfad, streng=False)
427            if manifest is None:
428                return None
429            lokal = manifest
430        dort = self.entfernter_stand(verzeichnis, frisch=frisch)
431        if dort is None:
432            return None
433        return Standvergleich(
434            verzeichnis, zeitpunkt(lokal), zeitpunkt(dort),
435            eingaben(dort) - eingaben(lokal) - self.verfuegbare_laeufe(),
436        )

438    def _warne_wenn_veraltet(self, rel: str) -> None:
439        """Beim Lesen: sagen, dass die lokale Fassung nicht die neueste ist.
440

443        nicht daran scheitern, dass das Netz weg ist.

446        if verzeichnis in self._gewarnt or verzeichnis.split("/")[0] not in ABGELEITET:

459                befund.satz(),

549                            gefunden.add(paths.relativ(praefix, rel))
550        if self.config.remote:

552                rel = objekt.key[len(praefix) + 1:] if praefix else objekt.key
553                if paths.versteckt(rel) or not passt(rel, muster):

558    def laeufe(self, prefix: str | Path, muster: str = f"**/run_*/{MANIFEST}", *,
559               status: frozenset[str] = FERTIG, streng: bool = False,
560               fehler: type[Exception] = PublishError) -> list[Lauf]:
561        """Fertige Laeufe unter ``prefix`` - lokal, auf S3 oder beides.
562
563        Jeder ``Lauf`` traegt seinen relativen Ablagepfad in ``relativ``;
564        ``verzeichnis`` ist der lokale Pfad, der bei einem S3-Lauf nicht
565        existieren muss. Ein Lauf, dessen Manifest nicht fertig sagt, gilt
566        nicht - auch nicht, wenn er lokal liegt und S3 einen fertigen hat.
567        """
568        praefix = paths.relativ(prefix)
569        gefunden: dict[str, Lauf] = {}
570        if self.config.liest_lokal:
571            wurzel = self.local_path(praefix)
572            for lauf in fertige_laeufe(wurzel, muster, streng=streng, fehler=fehler,
573                                       status=status):
574                rel = paths.relativ(praefix, lauf.verzeichnis.relative_to(wurzel).as_posix())
575                gefunden[rel] = Lauf(lauf.verzeichnis, lauf.manifest, rel)
576        if self.config.remote:
577            for objekt in self.client.list(praefix + "/" if praefix else ""):
578                if not objekt.key.endswith("/" + MANIFEST):
579                    continue
580                rel = objekt.key[len(praefix) + 1:] if praefix else objekt.key
581                if paths.versteckt(rel) or not passt(rel, muster):
582                    continue
583                rel_dir = objekt.key[: -len("/" + MANIFEST)]
584                if rel_dir in gefunden:
585                    continue
586                try:
587                    manifest = json.loads(self.client.get(objekt.key).decode("utf-8"))
588                except (OSError, ValueError) as error:
589                    raise fehler(f"Invalid manifest: {self.s3_path(objekt.key)}") from error
590                if str(manifest.get("status", "")).lower() not in status:
591                    LOG.warning("Lauf uebersprungen, nicht fertig: %s", self.s3_path(rel_dir))
592                    continue
593                gefunden[rel_dir] = Lauf(self.local_path(rel_dir), manifest, rel_dir)
594        return [gefunden[k] for k in sorted(gefunden)]

633    def publish_files(self, dateien: Iterable[str], *, ueberschreiben: bool = False) -> list[str]:
634        """Laedt lokale Dateien nach S3, ``manifest.json`` zuletzt.
635
636        Gibt zurueck, was jetzt oben liegt. Ohne S3 im Backend passiert
637        nichts; im Hybridmodus mit ``HYBRID_PUBLISH_AFTER_WRITE=false`` auch
638        nicht - dann steht es im Log.
639        """
640        liste = [paths.relativ(d) for d in dateien]
641        if not liste:
642            return []
643        if not self.config.publiziert:
644            if self.backend == "hybrid":
645                LOG.info("Not published (HYBRID_PUBLISH_AFTER_WRITE=false): %d file(s)", len(liste))
646            return []
647
648        reihenfolge = sorted(liste, key=lambda r: (r.rsplit("/", 1)[-1] == MANIFEST, r))
649        oben: list[str] = []
650        for rel in reihenfolge:
651            lokal = self.local_path(rel)
652            daten = lokal.read_bytes()
653            md5 = hashlib.md5(daten).hexdigest()
654
655            vorhanden = self.client.head(rel)
656            if vorhanden is not None:
657                if self._ist_identisch(rel, vorhanden, daten, md5):
658                    LOG.info("Already published, identical: %s", rel)
659                    oben.append(rel)
660                    continue
661                if not ueberschreiben:
662                    raise PublishError(
663                        f"{self.s3_path(rel)} existiert bereits mit anderem Inhalt "
664                        f"({vorhanden.size} Bytes, lokal {len(daten)}). Laeufe sind "
665                        "unveraenderlich; nichts wird still ueberschrieben."
666                    )
667                LOG.info("Replacing published table file: %s", rel)
668
669            try:
670                self.client.put(rel, daten)
671            except Exception as error:  # noqa: BLE001 - jede Transportstoerung ist hier gleich
672                raise PublishError(f"Upload fehlgeschlagen: {self.s3_path(rel)}: {error}") from error
673
674            nachher = self.client.head(rel)
675            if nachher is None or nachher.size != len(daten):
676                raise PublishError(
677                    f"Upload nicht bestaetigt: {self.s3_path(rel)} "
678                    f"({'fehlt' if nachher is None else f'{nachher.size} statt {len(daten)} Bytes'})"
679                )
680            if not self._ist_identisch(rel, nachher, daten, md5):
681                raise PublishError(f"Pruefsumme nach Upload weicht ab: {self.s3_path(rel)}")
682            LOG.info("Published: %s", rel)
683            oben.append(rel)
684        return oben

686    def _ist_identisch(self, rel: str, oben: Objekt, daten: bytes, md5: str) -> bool:
687        """Ob das Objekt oben byteweise dasselbe ist wie ``daten``.
688
689        **Gleiche Groesse ist kein Beweis.** Genau das stand hier bis zum
690        15.9.2026: Liess sich das ETag nicht als MD5 lesen, genuegte die
691        Byteanzahl - und drei Bytes ``NEU`` galten als identisch mit drei
692        Bytes ``ALT``. Der Upload unterblieb, und die Zusage unveraenderlicher
693        Laeufe ruhte auf einem Zufall.
694
695        Ein ETag ist nicht immer eine Pruefsumme: Bei mehrteiligen Uploads
696        setzt S3 einen Hash ueber die Teil-Hashes mit angehaengtem ``-N``.
697        Dann bleibt nur, den Inhalt zu holen und zu vergleichen. Das kostet
698        einen Download - aber nur dann, wenn die Groessen ohnehin gleich sind
699        und die Pruefsumme nichts hergibt.
700        """
701        if oben.size != len(daten):
702            return False
703        bekannt = etag_md5(oben.etag)
704        if bekannt is not None:
705            return bekannt == md5
706        LOG.info("ETag ist keine Pruefsumme (%s), Inhalt wird geholt: %s",
707                 oben.etag, self.s3_path(rel))
708        try:
709            return self.client.get(rel) == daten
710        except Exception as fehler:  # noqa: BLE001 - jede Transportstoerung ist hier gleich
711            raise PublishError(
712                f"Inhalt nicht pruefbar: {self.s3_path(rel)}: {fehler}. Das ETag "
713                "ist keine Pruefsumme, und der Vergleichsdownload scheiterte - "
714                "gleiche Groesse allein gilt nicht als gleicher Inhalt."
715            ) from fehler

772    def _entwerte_entferntes_manifest(self, rel: str) -> None:
773        """Das entfernte Manifest auf ``publishing`` setzen, bevor Daten fallen.
774
775        **Warum das noetig ist.** ``manifest.json`` zuletzt zu schreiben
776        schuetzt einen *neuen* Lauf: Ohne Manifest gilt er nicht. Eine
777        *bestehende* Tabelle schuetzt es nicht. Wird ihre Parquet-Datei
778        ueberschrieben und bricht danach der Manifest-Upload ab, liegt oben
779        der neue Inhalt unter dem alten Manifest - und das sagt weiterhin
780        ``complete``. Genau das war am 15.9.2026 in einer Gegenprobe zu sehen:
781        neue Daten, Bauzeitpunkt vom 1. August, Status ``complete``.
782
783        Deshalb faellt zuerst der Status. Ein Leser sieht danach der Reihe nach
784        den vollstaendigen alten Stand, dann *keinen* (``publishing`` zaehlt
785        nicht als fertig, siehe ``tabellen``), dann den vollstaendigen neuen.
786        Ein Abbruch dazwischen laesst die Tabelle unbrauchbar zurueck, nicht
787        falsch - und der naechste Lauf stellt sie her.
788
789        Was das **nicht** loest: Die fuenf Gold-Tabellen werden weiterhin
790        nacheinander publiziert. Ein gemeinsamer, konsistenter Stand ueber
791        alle Tabellen braucht Versionspfade und einen Verweis, der umgelegt
792        wird; das steht im Ausblick.
793        """
794        if not self.config.publiziert:
795            return
796        schluessel = paths.relativ(rel, MANIFEST)
797        oben = self.client.head(schluessel)
798        if oben is None:
799            return
800        try:
801            manifest = json.loads(self.client.get(schluessel).decode("utf-8"))
802        except (OSError, ValueError) as fehler:
803            raise PublishError(
804                f"Entferntes Manifest nicht lesbar: {self.s3_path(schluessel)}: {fehler}"
805            ) from fehler
806        if str(manifest.get("status", "")).lower() not in FERTIG:
807            return
808        manifest["status"] = "publishing"
809        manifest["superseded_at_utc"] = datetime.now(timezone.utc).isoformat(
810            timespec="seconds").replace("+00:00", "Z")
811        try:
812            self.client.put(schluessel, json.dumps(manifest, indent=2).encode("utf-8"))
813        except Exception as fehler:  # noqa: BLE001 - jede Transportstoerung ist hier gleich
814            raise PublishError(
815                f"Tabelle nicht entwertet, nichts angefasst: "
816                f"{self.s3_path(schluessel)}: {fehler}"
817            ) from fehler
818        LOG.info("Entferntes Manifest auf 'publishing' gesetzt: %s", schluessel)

821    #
822    # Bis zum 17.9.2026 galt: kein automatisches Herunterladen - was lokal
823    # fehlt, wird von S3 gelesen, nicht kopiert. Das bleibt fuer Silver und
824    # Gold richtig (Abschnitt 8 der Storage-Architektur: ein stiller Cache
825    # waere eine zweite Wahrheit mit eigenem Alter). Fuer Raw und Bronze gilt
826    # es nicht: Laeufe sind unveraenderlich, eine Kopie kann nicht veralten,
827    # und jeder Rechner soll den ganzen Bestand haben - Christian, 17.9.2026.
828    # Releases sind ebenso unveraenderlich; sie werden mit ``storage.release``
829    # geholt, ueber dieselben Bausteine hier.

831    def hole(self, rel: str | Path) -> Path:
832        """Ein Objekt von S3 in die lokale Wurzel - geprueft und unteilbar.
833
834        Liegt es lokal schon identisch, passiert nichts. Geschrieben wird in
835        eine ``.part``-Datei daneben, verglichen (Groesse, dann MD5 gegen das
836        ETag, wo der Dienst eines liefert), dann umbenannt.
837        """
838        rel = paths.relativ(rel)
839        if not self.config.remote:
840            raise PublishError(f"STORAGE_BACKEND={self.backend} kennt kein S3 - nichts zu holen")
841        oben = self.client.head(rel)
842        if oben is None:
843            raise StorageError(f"nicht auf SeaweedFS: {self.s3_path(rel)}")
844        ziel = self.local_path(rel)
845        if ziel.is_file() and ziel.stat().st_size == oben.size:
846            bekannt = etag_md5(oben.etag)
847            if bekannt is None or bekannt == hashlib.md5(ziel.read_bytes()).hexdigest():
848                LOG.debug("Already local, identical: %s", rel)
849                return ziel
850        try:
851            daten = self.client.get(rel)
852        except Exception as fehler:  # noqa: BLE001 - jede Transportstoerung ist hier gleich
853            raise StorageError(f"Download fehlgeschlagen: {self.s3_path(rel)}: {fehler}") from fehler
854        if len(daten) != oben.size:
855            raise StorageError(
856                f"Download unvollstaendig: {self.s3_path(rel)} "
857                f"({len(daten)} statt {oben.size} Bytes)"
858            )
859        bekannt = etag_md5(oben.etag)
860        if bekannt is not None and bekannt != hashlib.md5(daten).hexdigest():
861            raise StorageError(f"Pruefsumme nach Download weicht ab: {self.s3_path(rel)}")
862        ziel.parent.mkdir(parents=True, exist_ok=True)
863        arbeit = ziel.with_name(f".{ziel.name}.{id(self) & 0xffff:x}.part")
864        arbeit.write_bytes(daten)
865        arbeit.replace(ziel)
866        LOG.info("Fetched: %s", rel)
867        return ziel

931def glob_regex(muster: str) -> re.Pattern[str]:
932    """``Path.glob``-Semantik als Regex: ``*`` bleibt in seiner Ebene, ``**``
933    deckt null oder mehr Ebenen ab."""
934    teile = muster.split("/")
935    ausdruck = "^"
936    for i, teil in enumerate(teile):
937        letzter = i == len(teile) - 1
938        if teil == "**":
939            ausdruck += ".*" if letzter else "(?:[^/]+/)*"
940            continue
941        segment = ENDANKER.sub("", glob_translate(teil))
942        ausdruck += segment.replace(".*", "[^/]*") + ("" if letzter else "/")
943    return re.compile(ausdruck + "$")

394                         frisch: bool = False) -> Standvergleich | None:

396
397        ``None``, wenn nichts zu vergleichen ist: keine der beiden Seiten da,
398        oder eine Schicht, in der Staende einander nicht verdraengen.
399
400        **Was als fehlend zaehlt.** Bis zum 17.9.2026 galt jeder Lauf als
401        fehlend, den der Stand oben nennt und der hiesige nicht. Das war zu
402        streng, und es hat an diesem Abend einen Gesamtlauf abgebrochen:
403
404            silver/dataset=weather_day: hier gebaut 19:30 UTC, auf SeaweedFS

412        unter ``data/bronze``.

415        der Bau ihn benutzt hat. Die Absicht der Regel bleibt: Wer einen Lauf
416        geloescht oder nie geholt hat und daraus neu baut, verdraengt einen
417        reicheren Stand - und genau dann ist der Lauf auch nicht erreichbar.
418        Bei Chicagos Deltas aendert sich nichts: ``crime_offense`` liest alle
419        Laeufe, ein erreichbarer taucht dort immer auch in der Herkunft auf.

426                return None

428            if manifest is None:
429                return None

432        if dort is None:
433            return None

435            verzeichnis, zeitpunkt(lokal), zeitpunkt(dort),
436            eingaben(dort) - eingaben(lokal) - self.verfuegbare_laeufe(),
437        )

442        Eine Warnung, keine Absage - "lokal zuerst" bleibt die Regel. Faellt

553                rel = objekt.key[len(praefix) + 1:] if praefix else objekt.key

559    def laeufe(self, prefix: str | Path, muster: str = f"**/run_*/{MANIFEST}", *,
560               status: frozenset[str] = FERTIG, streng: bool = False,
561               fehler: type[Exception] = PublishError) -> list[Lauf]:
562        """Fertige Laeufe unter ``prefix`` - lokal, auf S3 oder beides.
563
564        Jeder ``Lauf`` traegt seinen relativen Ablagepfad in ``relativ``;
565        ``verzeichnis`` ist der lokale Pfad, der bei einem S3-Lauf nicht
566        existieren muss. Ein Lauf, dessen Manifest nicht fertig sagt, gilt
567        nicht - auch nicht, wenn er lokal liegt und S3 einen fertigen hat.
568        """
569        praefix = paths.relativ(prefix)
570        gefunden: dict[str, Lauf] = {}
571        if self.config.liest_lokal:
572            wurzel = self.local_path(praefix)
573            for lauf in fertige_laeufe(wurzel, muster, streng=streng, fehler=fehler,
574                                       status=status):
575                rel = paths.relativ(praefix, lauf.verzeichnis.relative_to(wurzel).as_posix())
576                gefunden[rel] = Lauf(lauf.verzeichnis, lauf.manifest, rel)
577        if self.config.remote:
578            for objekt in self.client.list(praefix + "/" if praefix else ""):
579                if not objekt.key.endswith("/" + MANIFEST):
580                    continue
581                rel = objekt.key[len(praefix) + 1:] if praefix else objekt.key
582                if paths.versteckt(rel) or not passt(rel, muster):
583                    continue
584                rel_dir = objekt.key[: -len("/" + MANIFEST)]
585                if rel_dir in gefunden:
586                    continue
587                try:
588                    manifest = json.loads(self.client.get(objekt.key).decode("utf-8"))
589                except (OSError, ValueError) as error:
590                    raise fehler(f"Invalid manifest: {self.s3_path(objekt.key)}") from error
591                if str(manifest.get("status", "")).lower() not in status:
592                    LOG.warning("Lauf uebersprungen, nicht fertig: %s", self.s3_path(rel_dir))
593                    continue
594                gefunden[rel_dir] = Lauf(self.local_path(rel_dir), manifest, rel_dir)
595        return [gefunden[k] for k in sorted(gefunden)]

634    def publish_files(self, dateien: Iterable[str], *, ueberschreiben: bool = False) -> list[str]:
635        """Laedt lokale Dateien nach S3, ``manifest.json`` zuletzt.
636
637        Gibt zurueck, was jetzt oben liegt. Ohne S3 im Backend passiert
638        nichts; im Hybridmodus mit ``HYBRID_PUBLISH_AFTER_WRITE=false`` auch
639        nicht - dann steht es im Log.
640        """
641        liste = [paths.relativ(d) for d in dateien]
642        if not liste:
643            return []
644        if not self.config.publiziert:
645            if self.backend == "hybrid":
646                LOG.info("Not published (HYBRID_PUBLISH_AFTER_WRITE=false): %d file(s)", len(liste))
647            return []
648
649        reihenfolge = sorted(liste, key=lambda r: (r.rsplit("/", 1)[-1] == MANIFEST, r))
650        oben: list[str] = []
651        for rel in reihenfolge:
652            lokal = self.local_path(rel)
653            daten = lokal.read_bytes()
654            md5 = hashlib.md5(daten).hexdigest()
655
656            vorhanden = self.client.head(rel)
657            if vorhanden is not None:
658                if self._ist_identisch(rel, vorhanden, daten, md5):
659                    LOG.info("Already published, identical: %s", rel)
660                    oben.append(rel)
661                    continue
662                if not ueberschreiben:
663                    raise PublishError(
664                        f"{self.s3_path(rel)} existiert bereits mit anderem Inhalt "
665                        f"({vorhanden.size} Bytes, lokal {len(daten)}). Laeufe sind "
666                        "unveraenderlich; nichts wird still ueberschrieben."
667                    )
668                LOG.info("Replacing published table file: %s", rel)
669
670            try:
671                self.client.put(rel, daten)
672            except Exception as error:  # noqa: BLE001 - jede Transportstoerung ist hier gleich
673                raise PublishError(f"Upload fehlgeschlagen: {self.s3_path(rel)}: {error}") from error
674
675            nachher = self.client.head(rel)
676            if nachher is None or nachher.size != len(daten):
677                raise PublishError(
678                    f"Upload nicht bestaetigt: {self.s3_path(rel)} "
679                    f"({'fehlt' if nachher is None else f'{nachher.size} statt {len(daten)} Bytes'})"
680                )
681            if not self._ist_identisch(rel, nachher, daten, md5):
682                raise PublishError(f"Pruefsumme nach Upload weicht ab: {self.s3_path(rel)}")
683            LOG.info("Published: %s", rel)
684            oben.append(rel)
685        return oben

687    def _ist_identisch(self, rel: str, oben: Objekt, daten: bytes, md5: str) -> bool:
688        """Ob das Objekt oben byteweise dasselbe ist wie ``daten``.
689
690        **Gleiche Groesse ist kein Beweis.** Genau das stand hier bis zum
691        15.9.2026: Liess sich das ETag nicht als MD5 lesen, genuegte die
692        Byteanzahl - und drei Bytes ``NEU`` galten als identisch mit drei
693        Bytes ``ALT``. Der Upload unterblieb, und die Zusage unveraenderlicher
694        Laeufe ruhte auf einem Zufall.
695
696        Ein ETag ist nicht immer eine Pruefsumme: Bei mehrteiligen Uploads
697        setzt S3 einen Hash ueber die Teil-Hashes mit angehaengtem ``-N``.
698        Dann bleibt nur, den Inhalt zu holen und zu vergleichen. Das kostet
699        einen Download - aber nur dann, wenn die Groessen ohnehin gleich sind
700        und die Pruefsumme nichts hergibt.
701        """
702        if oben.size != len(daten):
703            return False
704        bekannt = etag_md5(oben.etag)
705        if bekannt is not None:
706            return bekannt == md5
707        LOG.info("ETag ist keine Pruefsumme (%s), Inhalt wird geholt: %s",
708                 oben.etag, self.s3_path(rel))
709        try:
710            return self.client.get(rel) == daten
711        except Exception as fehler:  # noqa: BLE001 - jede Transportstoerung ist hier gleich
712            raise PublishError(
713                f"Inhalt nicht pruefbar: {self.s3_path(rel)}: {fehler}. Das ETag "
714                "ist keine Pruefsumme, und der Vergleichsdownload scheiterte - "
715                "gleiche Groesse allein gilt nicht als gleicher Inhalt."
716            ) from fehler

773    def _entwerte_entferntes_manifest(self, rel: str) -> None:
774        """Das entfernte Manifest auf ``publishing`` setzen, bevor Daten fallen.
775
776        **Warum das noetig ist.** ``manifest.json`` zuletzt zu schreiben
777        schuetzt einen *neuen* Lauf: Ohne Manifest gilt er nicht. Eine
778        *bestehende* Tabelle schuetzt es nicht. Wird ihre Parquet-Datei
779        ueberschrieben und bricht danach der Manifest-Upload ab, liegt oben
780        der neue Inhalt unter dem alten Manifest - und das sagt weiterhin
781        ``complete``. Genau das war am 15.9.2026 in einer Gegenprobe zu sehen:
782        neue Daten, Bauzeitpunkt vom 1. August, Status ``complete``.
783
784        Deshalb faellt zuerst der Status. Ein Leser sieht danach der Reihe nach
785        den vollstaendigen alten Stand, dann *keinen* (``publishing`` zaehlt
786        nicht als fertig, siehe ``tabellen``), dann den vollstaendigen neuen.
787        Ein Abbruch dazwischen laesst die Tabelle unbrauchbar zurueck, nicht
788        falsch - und der naechste Lauf stellt sie her.
789
790        Was das **nicht** loest: Die fuenf Gold-Tabellen werden weiterhin
791        nacheinander publiziert. Ein gemeinsamer, konsistenter Stand ueber
792        alle Tabellen braucht Versionspfade und einen Verweis, der umgelegt
793        wird; das steht im Ausblick.
794        """
795        if not self.config.publiziert:
796            return
797        schluessel = paths.relativ(rel, MANIFEST)
798        oben = self.client.head(schluessel)
799        if oben is None:
800            return
801        try:
802            manifest = json.loads(self.client.get(schluessel).decode("utf-8"))
803        except (OSError, ValueError) as fehler:
804            raise PublishError(
805                f"Entferntes Manifest nicht lesbar: {self.s3_path(schluessel)}: {fehler}"
806            ) from fehler
807        if str(manifest.get("status", "")).lower() not in FERTIG:
808            return
809        manifest["status"] = "publishing"
810        manifest["superseded_at_utc"] = datetime.now(timezone.utc).isoformat(
811            timespec="seconds").replace("+00:00", "Z")
812        try:
813            self.client.put(schluessel, json.dumps(manifest, indent=2).encode("utf-8"))
814        except Exception as fehler:  # noqa: BLE001 - jede Transportstoerung ist hier gleich
815            raise PublishError(
816                f"Tabelle nicht entwertet, nichts angefasst: "
817                f"{self.s3_path(schluessel)}: {fehler}"
818            ) from fehler
819        LOG.info("Entferntes Manifest auf 'publishing' gesetzt: %s", schluessel)

823    # Bis zum 17.9.2026 galt: kein automatisches Herunterladen - was lokal
824    # fehlt, wird von S3 gelesen, nicht kopiert. Das bleibt fuer Silver und
825    # Gold richtig (Abschnitt 8 der Storage-Architektur: ein stiller Cache
826    # waere eine zweite Wahrheit mit eigenem Alter). Fuer Raw und Bronze gilt
827    # es nicht: Laeufe sind unveraenderlich, eine Kopie kann nicht veralten,
828    # und jeder Rechner soll den ganzen Bestand haben - Christian, 17.9.2026.
829    # Releases sind ebenso unveraenderlich; sie werden mit ``storage.release``
830    # geholt, ueber dieselben Bausteine hier.

832    def hole(self, rel: str | Path) -> Path:
833        """Ein Objekt von S3 in die lokale Wurzel - geprueft und unteilbar.
834
835        Liegt es lokal schon identisch, passiert nichts. Geschrieben wird in
836        eine ``.part``-Datei daneben, verglichen (Groesse, dann MD5 gegen das
837        ETag, wo der Dienst eines liefert), dann umbenannt.
838        """
839        rel = paths.relativ(rel)
840        if not self.config.remote:
841            raise PublishError(f"STORAGE_BACKEND={self.backend} kennt kein S3 - nichts zu holen")
842        oben = self.client.head(rel)
843        if oben is None:
844            raise StorageError(f"nicht auf SeaweedFS: {self.s3_path(rel)}")
845        ziel = self.local_path(rel)
846        if ziel.is_file() and ziel.stat().st_size == oben.size:
847            bekannt = etag_md5(oben.etag)
848            if bekannt is None or bekannt == hashlib.md5(ziel.read_bytes()).hexdigest():
