storage.release

Der Veroeffentlichungsstand: ein Verzeichnis je Release, ein Zeiger darauf.

releases/release=2026-09-17T15-04-05Z/gold/dataset=fact_offense/part-0001storage.parquet
releases/release=2026-09-17T15-04-05Z/serving/dataset=comparison_day/...
releases/release=2026-09-17T15-04-05Z/serving/analysestorage.duckdb   <- selbstaendig
releases/release=2026-09-17T15-04-05Z/serving/tracts.geojson
releases/release=2026-09-17T15-04-05Z/release.json             <- Pruefsummen
releases/AKTUELL.json                                           <- der Zeiger

Was das loest. Bis zum 17.9.2026 wurden die fuenf Gold-Tabellen einzeln und nacheinander an festen Pfaden ueberschrieben. Zwischen fact_offense und dim_city_day lag ein Fenster, in dem eine Abfrage ueber beide einen gemischten Stand sah - und sobald ein Dashboard danebensteht, fragt jemand genau in diesem Fenster. Ein Release ist unveraenderlich und ganz: Geschrieben wird vollstaendig unter einer neuen Kennung, geprueft, und erst dann wird AKTUELL.json ersetzt - ein einziges Objekt, dessen Ersetzung lokal (rename) wie auf S3 (PUT) unteilbar ist. Alle Tabellen wechseln gemeinsam, ein Abbruch an jeder Stelle laesst den alten Stand gueltig.

Eine Kennung je Release, nicht je Tabelle. Ein frueherer Entwurf versionierte jede Tabelle fuer sich. Das ist beweglicher - und genau die Beweglichkeit ist die Moeglichkeit, aus der ein gemischter Stand entsteht. Gold wird ohnehin immer als Ganzes gebaut.

Die DuckDB im Release ist selbstaendig. Die Arbeitsdatenbank data/serving/analysestorage.duckdb haelt Sichten mit absoluten Pfaden; auf einem anderen Rechner ist sie wertlos. Die Datei im Release haelt Tabellen und ist ein Download, der sofort antwortet. Der Bestand bleibt Parquet - die DuckDB-Datei ist eine Ableitung davon und haengt an einer DuckDB-Version.

Was ein Release enthaelt: die fuenf Gold-Tabellen, die vier Serving-Tabellen, das GeoJSON, die selbstaendige Datenbank und release.json mit SHA-256 je Datei, Vertrags- und Code-Versionen, dem Eingabe-Abdruck, den Bronze-Laeufen, auf denen alles ruht, und - seit dem 4.10.2026, in neuen Manifesten - den Jahrgaengen, die der Stand traegt (years). Nicht enthalten: Silver und Bronze - die liegen an ihren festen Pfaden und sind ueber die Manifeste erreichbar.

Wie es auf SeaweedFS kommt. Wie ein Lauf: unveraenderlich, identisch oben wird uebersprungen, anders oben ist ein Fehler. release.json geht zuletzt hoch, dann wird AKTUELL.json ersetzt. Die festen Pfade gold/dataset=... werden weiterhin bedient - wer heute dort liest, liest weiter; das Release ist der Weg fuer alles, was einen ganzen Stand braucht.

Was bewusst nicht hier steht: die Aufbewahrungsregel. Seit dem 4.10.2026 gibt es sie - gepinnt plus die letzten acht, lokal und auf SeaweedFS -, und sie steht in orchestration.aufraeumen, nicht hier (docs/intern/datenhistorie.md 5.5). Dieses Modul bildet und liest Releases; was von ihnen bleibt, ist eine Frage der Steuerung. Entfernt wird ueber Storage.entferne_oben, und zwar release.json zuletzt - das Spiegelbild von "release.json geht zuletzt hoch": Solange das Manifest steht, findet liste das halb geleerte Release wieder.

Gemessen am 4.10.2026: 42,3 MB je Release - rund 15 MB Parquet plus eine 26,5 MB grosse Datenbank -, also rund 2,2 GB bei einem woechentlichen Release im Jahr. Die 49 Releases auf SeaweedFS waren zusammen 2,1 GB und 1'085 von 1'464 Objekten im Bucket; eine fruehere Fassung dieses Docstrings rechnete mit "unter einem Gigabyte im Jahr" und lag damit um mehr als das Doppelte daneben.

 86# Was in ein Release kommt: (Schicht, Muster relativ zur Schicht). Tabellen als
 87# ganze Verzeichnisse, die beiden Karten-Dateien einzeln.
 88INHALT: tuple[tuple[str, str], ...] = (
 89    ("gold", "dataset=*"),
 90    ("serving", "dataset=*"),
 91    ("serving", "tracts.geojson"),
 92    ("serving", "tracts.manifest.json"),
 93)
 94# Was mindestens dasein muss, damit ein Release eines ist. ``storage`` kennt
 95# nur Dateien, nicht die Schichten darueber - deshalb ist das hier ein Boden,
 96# und der Aufrufer reicht die vollstaendige Liste nach (``orchestration.release``).
 97#
 98# Warum es diesen Parameter gibt: Am 17.9.2026 wurde ``data/serving/``
 99# beiseitegeschoben und ein Release gebildet. Es entstand mit 11 statt 21
100# Dateien - ohne die vier Vergleichstabellen, ohne die Karte - und nannte sich
101# ``complete``. Ein Teilstand, dem man es nicht ansieht, ist schlimmer als
102# keiner.
103PFLICHT = ("gold/dataset=fact_offense",)

128def kennung_aus(verzeichnis_: Path | str) -> str:
129    name = str(verzeichnis_).replace("\\", "/").rstrip("/").rsplit("/", 1)[-1]

140def sammle(data_root: Path) -> list[tuple[Path, str]]:
141    """Was ins Release kommt: (lokale Datei, Pfad im Release).
142
143    Nur Tabellen mit fertigem Manifest zaehlen; ein ``.part`` daneben nie.
144    """
145    dateien: list[tuple[Path, str]] = []
146    for schicht, muster in INHALT:
147        wurzel = data_root / schicht
148        if not wurzel.is_dir():
149            continue
150        for treffer in sorted(wurzel.glob(muster)):
151            if paths.versteckt(treffer.relative_to(wurzel).as_posix()):
152                continue
153            if treffer.is_dir():
154                if not (treffer / MANIFEST).is_file():
155                    LOG.warning("Ohne Manifest, nicht im Release: %s", treffer)
156                    continue
157                manifest = read_manifest(treffer / MANIFEST, streng=False) or {}
158                if str(manifest.get("status", "")).lower() not in {"complete", "success"}:
159                    LOG.warning("Nicht fertig, nicht im Release: %s", treffer)
160                    continue
161                for datei in sorted(treffer.rglob("*")):
162                    rel = datei.relative_to(wurzel).as_posix()
163                    if datei.is_file() and not paths.versteckt(rel):
164                        dateien.append((datei, paths.relativ(schicht, rel)))
165            elif treffer.is_file():
166                dateien.append((treffer, paths.relativ(schicht, treffer.name)))
167    return dateien

170def sha256(pfad: Path) -> str:
171    h = hashlib.sha256()
172    with pfad.open("rb") as datei:
173        for block in iter(lambda: datei.read(1 << 20), b""):
174            h.update(block)
175    return h.hexdigest()

178def tabellen_im(arbeit: Path) -> list[tuple[str, Path, dict[str, Any]]]:
179    """(Name, Parquet, Manifest) jeder Tabelle im Release, nach Schicht und Name."""
180    gefunden = []
181    for manifest_pfad in sorted(arbeit.glob(f"*/dataset=*/{MANIFEST}")):
182        name = manifest_pfad.parent.name.removeprefix("dataset=")
183        gefunden.append((name, manifest_pfad.parent / PARQUET_FILE,
184                         read_manifest(manifest_pfad)))
185    return gefunden

188def release_manifest(arbeit: Path, kennung_: str, jetzt: datetime,
189                     jahre: Iterable[int] = ()) -> dict[str, Any]:
190    """Was ueber diesen Stand gesagt werden darf - aus den Manifesten darin.
191
192    ``jahre`` sind die Jahrgaenge, die der Lauf gebaut hat, der dieses Release
193    bildet (``orchestration.run_all`` kennt sie, ``storage`` nicht). Sie landen
194    als ``years`` im Manifest, denn aus dem Release selbst sind sie nicht
195    ablesbar: Gold und Serving liegen an Pfaden ohne ``year=``, eine
196    Jahresspalte steckt in den Parquet-Dateien, und ``storage`` liest keine
197    Zeilen. Wer wissen will, wie viel Mehrjahrigkeit in diesen Bytes steckt -
198    ``orchestration.platzbedarf`` will es -, musste es bis zum 4.10.2026 ueber
199    ``pipeline_run.json`` erschliessen und durfte es nur glauben, wenn dieses
200    Protokoll genau diesen Stand benannte.
201
202    Leer heisst **nicht** "keine Jahrgaenge", sondern "nicht gesagt": Dann
203    fehlt der Schluessel, wie er in jedem Manifest vor dem 4.10.2026 fehlt.
204    Abgelegte Manifeste bleiben unveraenderlich; nachgetragen wird nichts.
205    """
206    tabellen: dict[str, Any] = {}
207    vertraege: dict[str, int] = {}
208    abdruck = None
209    herkunft: dict[str, Any] = {}
210    gate = None
211    for name, parquet, manifest in tabellen_im(arbeit):
212        schicht = parquet.parent.parent.name
213        tabellen[f"{schicht}/{name}"] = {
214            "rows": manifest.get("row_count", manifest.get("rows")),
215            "contract_version": manifest.get("contract_version"),
216            "built_at_utc": manifest.get("built_at_utc"),
217            "input_fingerprint": manifest.get("input_fingerprint"),
218        }
219        if manifest.get("contract_version") is not None:
220            vertraege[schicht if schicht == "gold" else f"{schicht}/{name}"] = \
221                manifest["contract_version"]
222        if name == "fact_offense":
223            abdruck = manifest.get("input_fingerprint")
224            herkunft = manifest.get("derived_from", {})
225            gate = (manifest.get("reconciliation") or {}).get("coverage_percent")
226    if not tabellen:
227        raise ReleaseFehler(f"Kein Manifest unter {arbeit} - nichts, worueber ein "
228                            "Release etwas sagen koennte")
229
230    dateien = {
231        p.relative_to(arbeit).as_posix(): {"sha256": sha256(p), "bytes": p.stat().st_size}
232        for p in sorted(arbeit.rglob("*"))
233        if p.is_file() and p.name != RELEASE_MANIFEST
234    }
235    gebaut = tuple(sorted({int(jahr) for jahr in jahre}))
236    return {
237        "status": "complete",
238        "release_id": kennung_,
239        "created_at_utc": jetzt.isoformat(timespec="seconds").replace("+00:00", "Z"),
240        **({"years": list(gebaut)} if gebaut else {}),
241        "code_version": code_stand(),
242        "contract_versions": vertraege,
243        "input_fingerprint": abdruck,
244        "derived_from": herkunft,
245        "gate": gate,
246        "tables": tabellen,
247        "files": dateien,
248        "bytes": sum(d["bytes"] for d in dateien.values()),
249    }

255def erstelle(data_root: Path, *, ergaenze: Ergaenzung | None = None,
256             pflicht: Iterable[str] = PFLICHT, jahre: Iterable[int] = (),
257             kennung_: str | None = None, jetzt: datetime | None = None,
258             aktivieren: bool = True) -> Path:
259    """Bildet ein Release lokal - vollstaendig oder gar nicht.
260
261    Kopiert Gold und Serving, ruft ``ergaenze(arbeit, kern)`` - dort baut der
262    Aufrufer, was ausser Kopien ins Release gehoert, etwa die selbstaendige
263    Datenbank (``orchestration.release``) -, schreibt ``release.json`` und
264    benennt zuletzt um. Danach zeigt das lokale ``AKTUELL.json`` darauf. Ein
265    Abbruch laesst nichts Halbes zurueck.
266
267    ``jahre`` nennt die Jahrgaenge, die in diesem Stand stecken - der Aufrufer
268    weiss sie, das Release sagt sie nicht von sich aus (``release_manifest``).
269    Ohne Angabe fehlt der Schluessel; geraten wird hier nichts.
270
271    ``aktivieren=False`` baut einen **Kandidaten**: ein vollstaendiges,
272    unveraenderliches Release, auf das ``AKTUELL.json`` nicht zeigt. Die
273    Engineering-Konsole braucht das - ihr Stand gilt erst nach dem Review,
274    und bis dahin lesen Analysen den bisherigen.
275
276    **Warum die Datenbank nicht hier gebaut wird.** ``storage`` ist ein
277    Fundament: Es weiss, wie man Dateien ablegt und publiziert, nicht, was
278    darin steht. Der Bau der Datenbank gehoert zu ``serving``, und ``serving``
279    haengt an ``storage`` - anders herum waere es ein Zyklus, und der Wächter
280    ueber den Importgraphen hat ihn beim ersten Versuch auch gefunden.
281    """
282    jetzt = jetzt or datetime.now(timezone.utc)
283    kennung_ = kennung_ or kennung(jetzt)
284    ziel = verzeichnis(data_root, kennung_)
285    if ziel.exists():
286        raise ReleaseFehler(f"Release gibt es schon: {ziel}. Releases sind "
287                            "unveraenderlich; eine neue Kennung bekommt der naechste Lauf.")
288
289    dateien = sammle(data_root)
290    # Ein Eintrag der Pflichtliste ist entweder ein Tabellenverzeichnis
291    # (``gold/dataset=fact_offense``) oder eine Datei (``serving/tracts.geojson``).
292    vorhanden = {rel for _, rel in dateien} | {rel.rsplit("/", 1)[0] for _, rel in dateien}
293    fehlend = [p for p in pflicht if p not in vorhanden]
294    if fehlend:
295        raise ReleaseFehler(
296            f"Kein Release, es fehlt: {', '.join(fehlend)}. Ein Release ist der "
297            "ganze Stand oder keiner - ein Teilstand, dem man es nicht ansieht, "
298            "waere schlimmer als gar keiner. Zuerst bauen: "
299            "python -m orchestration.run_all --ohne-ingestion"
300        )
301
302    arbeit = ziel.parent / f".{ziel.name}.part"
303    shutil.rmtree(arbeit, ignore_errors=True)
304    arbeit.mkdir(parents=True)
305    try:
306        for quelle, rel in dateien:
307            (arbeit / rel).parent.mkdir(parents=True, exist_ok=True)
308            shutil.copy2(quelle, arbeit / rel)
309
310        if ergaenze is not None:
311            ergaenze(arbeit, {
312                "release_id": kennung_,
313                "created_at_utc": jetzt.isoformat(timespec="seconds").replace("+00:00", "Z"),
314            })
315
316        manifest = release_manifest(arbeit, kennung_, jetzt, jahre)
317        (arbeit / RELEASE_MANIFEST).write_text(
318            json.dumps(manifest, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")
319        arbeit.rename(ziel)
320    except BaseException:
321        shutil.rmtree(arbeit, ignore_errors=True)
322        raise
323
324    if aktivieren:
325        setze_aktuell(data_root / RELEASES / AKTUELL, manifest)
326    LOG.info("Release %s: %d Dateien, %.1f MB -> %s",
327             kennung_, len(manifest["files"]), manifest["bytes"] / 1e6, ziel)
328    return ziel

340def setze_aktuell(pfad: Path, manifest: dict[str, Any]) -> None:
341    """Der lokale Zeiger - ueber ``.part`` und ``rename``, also unteilbar."""
342    pfad.parent.mkdir(parents=True, exist_ok=True)
343    arbeit = pfad.with_name(f".{pfad.name}.part")
344    arbeit.write_text(json.dumps(zeiger(manifest), indent=2) + "\n", encoding="utf-8")
345    arbeit.replace(pfad)

348def lies(verzeichnis_: Path) -> dict[str, Any]:
349    pfad = verzeichnis_ / RELEASE_MANIFEST
350    if not pfad.is_file():
351        raise ReleaseFehler(f"kein {RELEASE_MANIFEST} in {verzeichnis_}")
352    return read_manifest(pfad, fehler=ReleaseFehler)

360def publiziere(storage: Storage, verzeichnis_: Path) -> list[str]:
361    """Bringt ein Release nach SeaweedFS und legt den Zeiger um.
362
363    Unveraenderlich wie ein Lauf: identisch oben wird uebersprungen, anders
364    oben ist ein Fehler. ``release.json`` geht zuletzt hoch; erst dann wird
365    ``AKTUELL.json`` ersetzt. Ohne publizierenden Modus passiert nichts,
366    und das steht im Log.
367    """
368    if not storage.config.publiziert:
369        LOG.info("Release nicht publiziert (STORAGE_BACKEND=%s): %s",
370                 storage.backend, verzeichnis_)
371        return []
372    rel = storage.relativ(verzeichnis_)
373    if rel is None:
374        raise ReleaseFehler(f"ausserhalb der Ablagewurzel: {verzeichnis_}")
375    manifest = lies(verzeichnis_)
376
377    alle = [paths.relativ(rel, r) for r in manifest["files"]]
378    oben = storage.publish_files(alle, ueberschreiben=False)
379    oben += storage.publish_files([paths.relativ(rel, RELEASE_MANIFEST)], ueberschreiben=False)
380
381    schluessel = paths.relativ(RELEASES, AKTUELL)
382    try:
383        storage.client.put(schluessel, (json.dumps(zeiger(manifest), indent=2) + "\n").encode("utf-8"))
384    except Exception as fehler:  # noqa: BLE001 - jede Transportstoerung ist hier gleich
385        raise PublishError(f"Zeiger nicht umgelegt: {storage.s3_path(schluessel)}: {fehler}") from fehler
386    oben.append(schluessel)
387    LOG.info("AKTUELL.json zeigt auf %s", manifest["release_id"])
388
389    if storage.backend == "s3":
390        shutil.rmtree(verzeichnis_, ignore_errors=True)
391        LOG.info("Local release removed (STORAGE_BACKEND=s3): %s", rel)
392    return oben

416def hole(storage: Storage, was: str = "aktuell", *, nur_datenbank: bool = False) -> Path:
417    """Ein Release von SeaweedFS in die lokale Wurzel - geprueft gegen ``release.json``.
418
419    ``was`` ist eine Kennung oder ``aktuell``. Zuerst kommt ``release.json``,
420    dann jede Datei darin; jede wird gegen ihre SHA-256 gehalten, nicht nur
421    gegen das ETag. ``nur_datenbank`` holt allein ``serving/analyse.duckdb`` -
422    fuer ein Dashboard, das nichts anderes braucht (Rat vom 17.9.2026,
423    Schritte 3 bis 5). Was schon identisch da ist, wird nicht erneut geladen.
424    """
425    if was == "aktuell":
426        zeiger = aktuell(storage)
427        if zeiger is None:
428            raise ReleaseFehler("Kein Zeiger - es wurde noch kein Release publiziert.")
429        was = zeiger["release_id"]
430    rel = relativ(was)
431    manifest_pfad = storage.hole(paths.relativ(rel, RELEASE_MANIFEST))
432    manifest = lies(manifest_pfad.parent)
433    gewollt = [r for r in manifest["files"]
434               if not nur_datenbank or r.endswith("/" + DATENBANK)]
435    if nur_datenbank and not gewollt:
436        raise ReleaseFehler(f"Release {was} enthaelt keine {DATENBANK}")
437    for r in gewollt:
438        pfad = storage.local_path(rel, r)
439        angabe = manifest["files"][r]
440        if pfad.is_file() and pfad.stat().st_size == angabe["bytes"] \
441                and sha256(pfad) == angabe["sha256"]:
442            continue
443        storage.hole(paths.relativ(rel, r))
444        if sha256(pfad) != angabe["sha256"]:
445            pfad.unlink(missing_ok=True)
446            raise ReleaseFehler(
447                f"{r}: SHA-256 stimmt nicht mit release.json ueberein - die Datei "
448                "oben ist nicht die, die das Release beschreibt. Geloescht."
449            )
450    ziel = manifest_pfad.parent
451    if not nur_datenbank:
452        setze_aktuell(storage.local_path(RELEASES, AKTUELL), manifest)
453    LOG.info("Release %s geholt: %d Datei(en) -> %s", was, len(gewollt), ziel)
454    return ziel

457def einsetzen(data_root: Path, verzeichnis_: Path) -> list[Path]:
458    """Die Tabellen eines Release an ihre festen Pfade setzen - Tabelle fuer Tabelle unteilbar.
459

461    Stand. Die Manifeste kommen mit, deshalb sieht auch der Standvergleich der
462    Ablage (Abschnitt 8) denselben Bauzeitpunkt wie oben. Eingesetzt wird nur,
463    was das Release gegen seine Pruefsummen bestanden hat - also nur, was
464    ``hole`` oder ``erstelle`` hingelegt hat.
465    """

467    tabellen = sorted({r.rsplit("/", 1)[0] for r in manifest["files"] if "/dataset=" in r})
468    eingesetzt: list[Path] = []
469    for rel_dir in tabellen:
470        quelle = verzeichnis_ / rel_dir
471        for r, angabe in manifest["files"].items():
472            if r.startswith(rel_dir + "/") and sha256(verzeichnis_ / r) != angabe["sha256"]:

476        verdraengt = ziel.parent / f".{ziel.name}.release.superseded"
477        shutil.rmtree(arbeit, ignore_errors=True)
478        shutil.rmtree(verdraengt, ignore_errors=True)
479        shutil.copytree(quelle, arbeit)
480        try:
481            if ziel.exists():
482                ziel.rename(verdraengt)
483            arbeit.rename(ziel)
484            shutil.rmtree(verdraengt, ignore_errors=True)
485        except BaseException:

487            if verdraengt.exists() and not ziel.exists():
488                verdraengt.rename(ziel)

497            shutil.copy2(quelle, arbeit)
498            arbeit.replace(ziel)
499            eingesetzt.append(ziel)
500    LOG.info("Release %s eingesetzt: %d Tabellen", manifest["release_id"], len(tabellen))

def hole( storage: storage.Storage, was: str = 'aktuell', *, nur_datenbank: bool = False) -> pathlib._local.Path: 
417def hole(storage: Storage, was: str = "aktuell", *, nur_datenbank: bool = False) -> Path:
418    """Ein Release von SeaweedFS in die lokale Wurzel - geprueft gegen ``release.json``.
419
420    ``was`` ist eine Kennung oder ``aktuell``. Zuerst kommt ``release.json``,
421    dann jede Datei darin; jede wird gegen ihre SHA-256 gehalten, nicht nur
422    gegen das ETag. ``nur_datenbank`` holt allein ``serving/analyse.duckdb`` -
423    fuer ein Dashboard, das nichts anderes braucht (Rat vom 17.9.2026,
424    Schritte 3 bis 5). Was schon identisch da ist, wird nicht erneut geladen.
425    """
426    if was == "aktuell":
427        zeiger = aktuell(storage)
428        if zeiger is None:
429            raise ReleaseFehler("Kein Zeiger - es wurde noch kein Release publiziert.")
430        was = zeiger["release_id"]
431    rel = relativ(was)
432    manifest_pfad = storage.hole(paths.relativ(rel, RELEASE_MANIFEST))
433    manifest = lies(manifest_pfad.parent)
434    gewollt = [r for r in manifest["files"]
435               if not nur_datenbank or r.endswith("/" + DATENBANK)]
436    if nur_datenbank and not gewollt:
437        raise ReleaseFehler(f"Release {was} enthaelt keine {DATENBANK}")
438    for r in gewollt:
439        pfad = storage.local_path(rel, r)
440        angabe = manifest["files"][r]
441        if pfad.is_file() and pfad.stat().st_size == angabe["bytes"] \
442                and sha256(pfad) == angabe["sha256"]:
443            continue
444        storage.hole(paths.relativ(rel, r))
445        if sha256(pfad) != angabe["sha256"]:
446            pfad.unlink(missing_ok=True)
447            raise ReleaseFehler(
448                f"{r}: SHA-256 stimmt nicht mit release.json ueberein - die Datei "
449                "oben ist nicht die, die das Release beschreibt. Geloescht."
450            )
451    ziel = manifest_pfad.parent
452    if not nur_datenbank:
453        setze_aktuell(storage.local_path(RELEASES, AKTUELL), manifest)
454    LOG.info("Release %s geholt: %d Datei(en) -> %s", was, len(gewollt), ziel)
455    return ziel

def einsetzen( data_root: pathlib._local.Path, verzeichnis_: pathlib._local.Path) -> list[pathlib._local.Path]: 
458def einsetzen(data_root: Path, verzeichnis_: Path) -> list[Path]:
459    """Die Tabellen eines Release an ihre festen Pfade setzen - Tabelle fuer Tabelle unteilbar.
460
461    Danach liest, wer ``gold/dataset=...`` liest, genau den freigegebenen
462    Stand. Die Manifeste kommen mit, deshalb sieht auch der Standvergleich der
463    Ablage (Abschnitt 8) denselben Bauzeitpunkt wie oben. Eingesetzt wird nur,
464    was das Release gegen seine Pruefsummen bestanden hat - also nur, was
465    ``hole`` oder ``erstelle`` hingelegt hat.
466    """
467    manifest = lies(verzeichnis_)
468    tabellen = sorted({r.rsplit("/", 1)[0] for r in manifest["files"] if "/dataset=" in r})
469    eingesetzt: list[Path] = []
470    for rel_dir in tabellen:
471        quelle = verzeichnis_ / rel_dir
472        for r, angabe in manifest["files"].items():
473            if r.startswith(rel_dir + "/") and sha256(verzeichnis_ / r) != angabe["sha256"]:
474                raise ReleaseFehler(f"{r}: Pruefsumme stimmt nicht - nicht eingesetzt")
475        ziel = data_root / rel_dir
476        arbeit = ziel.parent / f".{ziel.name}.release.part"
477        verdraengt = ziel.parent / f".{ziel.name}.release.superseded"
478        shutil.rmtree(arbeit, ignore_errors=True)
479        shutil.rmtree(verdraengt, ignore_errors=True)
480        shutil.copytree(quelle, arbeit)
481        try:
482            if ziel.exists():
483                ziel.rename(verdraengt)
484            arbeit.rename(ziel)
485            shutil.rmtree(verdraengt, ignore_errors=True)
486        except BaseException:
487            shutil.rmtree(arbeit, ignore_errors=True)
488            if verdraengt.exists() and not ziel.exists():
489                verdraengt.rename(ziel)
490            raise
491        eingesetzt.append(ziel)
492    for name in ("tracts.geojson", "tracts.manifest.json"):
493        quelle = verzeichnis_ / "serving" / name
494        if quelle.is_file():
495            ziel = data_root / "serving" / name
496            ziel.parent.mkdir(parents=True, exist_ok=True)
497            arbeit = ziel.with_name(f".{name}.release.part")
498            shutil.copy2(quelle, arbeit)
499            arbeit.replace(ziel)
500            eingesetzt.append(ziel)
501    LOG.info("Release %s eingesetzt: %d Tabellen", manifest["release_id"], len(tabellen))
502    return eingesetzt
