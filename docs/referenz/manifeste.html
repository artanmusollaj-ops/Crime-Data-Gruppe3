manifeste

Ein Leser fuer die Manifeste - statt elf.

Jede Schicht schreibt je Lauf oder Tabelle ein manifest.json. Es zu finden und zu lesen war am 13.9. an elf Stellen implementiert, jede ein wenig anders: sieben kannten nur complete, Detroits Leser nur SUCCESS, der Controller beide; drei uebersprangen versteckte .part-Verzeichnisse, die uebrigen nicht; die Ingestion warf bei kaputtem JSON, der Controller warnte. Als der Controller entstand, musste er jede dieser Eigenheiten einzeln nachvollziehen - und vier der elf Stellen stammten vom selben Tag.

Hier steht es einmal. Was sich je Aufrufer unterscheidet, ist ein Parameter:

  • muster - wo die Manifeste liegen (run_*/manifest.json, ingest_date=*/run_*/manifest.json ...)
  • fehler - welche Ausnahme ein kaputtes Manifest ausloest. Die Ingestion sagt IngestionError, Silver TransformError; ihre Tests haengen an diesen Typen
  • streng - ob ein kaputtes Manifest wirft oder nur gewarnt wird. Fuer eine Pipeline ist es ein Fehler in der eigenen Schicht; fuer den Controller, der nur inventarisiert, eine Warnung

Was nicht hierhergehoert: detroit_pipeline.bronze_manifest.validate_manifest. Das ist kein Leser, sondern ein Zulassungstor mit Pruefsummen, Zeilenzahlen und Schema-Fingerabdruck. Es prueft, ob ein Lauf gilt - hier wird nur gefunden, ob er fertig ist.

 65class Lauf(NamedTuple):
 66    """Ein fertiger Lauf: sein Verzeichnis und sein Manifest.
 67
 68    ``relativ`` ist der Ablagepfad unter der Wurzel (``bronze/city=.../run_x``),
 69    gesetzt von ``storage.Storage.laeufe``; bei einem Lauf, der nur auf S3
 70    liegt, existiert ``verzeichnis`` lokal nicht.
 71    """
 72
 73    verzeichnis: Path
 74    manifest: dict[str, Any]
 75    relativ: str = ""
 76
 77    @property
 78    def run_id(self) -> str:
 79        # Chicago, Census, NOAA: run_id. Detroit: pipeline_run_id.
 80        return str(
 81            self.manifest.get("run_id")
 82            or self.manifest.get("pipeline_run_id")
 83            or self.verzeichnis.name
 84        )
 85
 86    @property
 87    def begonnen_um(self) -> str:
 88        # started_at bei Detroit, started_at_utc bei Chicago, Census, TIGER
 89        # und NOAA. Gebraucht wird er, wo Laeufe in ihre zeitliche Reihenfolge
 90        # gebracht werden muessen: Detroits Laufverzeichnisse heissen nach
 91        # einer UUID und sagen nichts ueber die Reihenfolge.
 92        return str(
 93            self.manifest.get("started_at")
 94            or self.manifest.get("started_at_utc")
 95            or ""
 96        )
 97
 98    @property
 99    def jahrgang(self) -> str:
100        """Der Jahrgang, den der Lauf geladen hat - leer, wenn keiner dasteht.
101
102        Chicago nennt ihn ``event_year``, Detroit ``year``: dieselbe
103        Asymmetrie wie bei ``mode``/``extraction_mode`` und
104        ``started_at``/``started_at_utc``, und sie gehoert aus demselben Grund
105        hierher und nicht in jedes Modul.
106
107        **Warum er gebraucht wird.** Beide Staedte laden seit dem 4.10.2026
108        **je Jahrgang**. Ein Vollabzug sagt damit nicht "das ist der ganze
109        Bestand", sondern "das ist der ganze Jahrgang 2024" - und Abwesenheit
110        darin heisst *nicht mehr in diesem Jahrgang*. Wer zwei Vollabzuege
111        vergleicht, ohne auf den Jahrgang zu sehen, vergleicht 2024 gegen
112        2021: Am 17.10.2026 standen so **1,64 Mio. erfundene
113        "verschwunden"** und 1,53 Mio. erfundene "neu" in
114        ``silver/source_change``, und ``silver/crime_offense`` hielt 89
115        zurueckgezogene Zeilen fest. Zwei Fehler, ein Denkfehler.
116        """
117        for schluessel in ("event_year", "year"):
118            wert = self.manifest.get(schluessel)
119            if wert not in (None, ""):
120                return str(wert)
121        return ""
122
123    @property
124    def vollabzug(self) -> bool:
125        """Ob der Lauf ein Vollschnappschuss ist - und nicht ein Delta.
126
127        Wer Schnappschuesse vergleicht, darf nur Vollabzuege nehmen: Ein Delta
128        enthaelt nur die bewegten Zeilen, und *was fehlt* laesst sich darin
129        nicht von *was sich nicht geaendert hat* unterscheiden.
130        """
131        return str(
132            self.manifest.get("extraction_mode")
133            or self.manifest.get("mode")
134            or ""
135        ).lower() in VOLLABZUG
136
137    @property
138    def abgeschlossen_um(self) -> str:
139        # completed_at_utc bei acht Modulen, finished_at bei Detroit.
140        return str(
141            self.manifest.get("completed_at_utc")
142            or self.manifest.get("finished_at")
143            or self.manifest.get("built_at_utc")
144            or ""
145        )
146
147    @property
148    def zeilen(self) -> int:
149        # row_count bei acht Modulen, downloaded_count bei Detroit.
150        return int(
151            self.manifest.get("row_count")
152            or self.manifest.get("downloaded_count")
153            or 0
154        )
155
156    def datei(self, vorgabe: str = PARQUET_FILE) -> Path:
157        """Die Datendatei des Laufs - Detroit nennt sie im Manifest."""
158        return self.verzeichnis / str(self.manifest.get("bronze_file") or vorgabe)

179# Die Projektwurzel - genannt oder erkannt, nie geraten
180# --------------------------------------------------------------------------
181# Bis zum 6.10.2026 stand an zwei Stellen dieselbe Formel:
182# ``Path(__file__).resolve().parents[3]``. Sie trifft genau einen Fall, die
183# editierbare Installation im Projekt - und raet in jedem anderen. Im Abbild
184# liegt das Paket zwar wieder editierbar unter ``/app``, aber die Formel sagt
185# das nicht, sie zaehlt nur Ebenen. Hier steht sie einmal, und sie prueft
186# ihr Ergebnis, statt es anzunehmen.
187
188#: Die Umgebungsvariable, die die Wurzel ausdruecklich nennt. Das ``Dockerfile``
189#: setzt sie; auf einem Entwicklungsrechner braucht sie niemand zu setzen.
190WURZEL_VARIABLE = "PROJECT_ROOT"
191
192#: Woran eine Projektwurzel erkennbar ist. ``config/`` steht hier, weil die
193#: Stufen ihre Crosswalks **relativ** aufloesen (``--config-root``, Vorgabe
194#: ``config``) - ein Arbeitsverzeichnis ohne sie laesst Gold mit einer leeren
195#: Dimension durchlaufen. ``pyproject.toml`` steht daneben, damit nicht jedes
196#: Verzeichnis mit einem Ordner ``config`` als Wurzel durchgeht.
197WURZELZEICHEN = ("pyproject.toml", "config")

200def ist_projektwurzel(pfad: Path) -> bool:
201    """Traegt dieses Verzeichnis beide Kennzeichen?"""
202    return all((pfad / zeichen).exists() for zeichen in WURZELZEICHEN)

205def projektwurzel(umgebung: Mapping[str, str] | None = None) -> Path | None:
206    """Das Projektverzeichnis - aus der Umgebung oder an der Paketlage erkannt.
207
208    Zwei Quellen, in dieser Reihenfolge:
209
210    1. ``PROJECT_ROOT`` aus der Umgebung. Was dort steht, gilt - und wird
211       geprueft: Zeigt die Angabe auf etwas, das die Kennzeichen nicht traegt,
212       ist das ein Konfigurationsfehler und **kein** Grund, doch wieder zu
213       raten. Dann kommt ``None`` zurueck, mit einer Zeile im Log.
214    2. Die Lage des Pakets. Von diesem Modul aufwaerts, bis ein Verzeichnis
215       beide Kennzeichen traegt. Bei ``pip install -e .`` ist das das Projekt;
216       bei einer gewoehnlichen Installation nach ``site-packages`` findet sich
217       keines - und genau dort log die alte Formel falsch.
218
219    ``None`` heisst *nicht ableitbar*. Wer die Wurzel braucht, bricht damit ab
220    und sagt, was zu setzen ist (``orchestration.run_all``); wer sie nur
221    gebrauchen koennte, laeuft ohne sie weiter (``code_stand``).
222    """
223    umgebung = os.environ if umgebung is None else umgebung
224    genannt = (umgebung.get(WURZEL_VARIABLE) or "").strip()
225    if genannt:
226        wurzel = Path(genannt).expanduser()
227        if ist_projektwurzel(wurzel):
228            return wurzel.resolve()
229        LOG.error("%s=%s traegt nicht %s - die Angabe wird nicht ersetzt.",
230                  WURZEL_VARIABLE, genannt, " und ".join(WURZELZEICHEN))
231        return None
232    for kandidat in Path(__file__).resolve().parents:
233        if ist_projektwurzel(kandidat):
234            return kandidat
235    return None

238#: Die Umgebungsvariable, aus der der Commit kommt, wenn Git nichts hergibt.
239#: Das ``Dockerfile`` nimmt ihn als ``ARG GIT_COMMIT`` entgegen und setzt ihn
240#: hier hinein. Ohne diesen Weg stuende in jedem Manifest aus dem Container
241#: "welcher Code das erzeugt hat: unbekannt" - denn ``.git/`` gehoert nicht
242#: ins Abbild (FR-2), und ein Projekt, dessen Kern die Belegbarkeit ist, darf
243#: die Herkunft nicht fuer eine Zeile in der ``.dockerignore`` hergeben.
244COMMIT_VARIABLE = "GIT_COMMIT"
245
246
247def aus_der_umgebung(umgebung: Mapping[str, str] | None = None) -> str | None:
248    """Der Commit aus ``GIT_COMMIT`` - oder ``None``, wenn dort nichts Gueltiges steht."""
249    umgebung = os.environ if umgebung is None else umgebung
250    genannt = (umgebung.get(COMMIT_VARIABLE) or "").strip().lower()
251    if not genannt:
252        return None
253    if re.fullmatch(r"[0-9a-f]{40}", genannt):
254        return genannt
255    LOG.warning("%s=%s ist keine volle Commit-Kennung - die Herkunft bleibt leer.",
256                COMMIT_VARIABLE, genannt)
257    return None

260@lru_cache(maxsize=1)
261def code_stand() -> dict[str, Any]:
262    """Welcher Code diesen Lauf erzeugt hat - Commit und Sauberkeit.
263
264    Das ist die **forensische** Haelfte der Frage *"ab wann wurden die Daten
265    anders geladen?"*: Der Commit sagt genau, welcher Code lief. Was er nicht
266    sagt, ist ob sich die **Bedeutung** geaendert hat - er springt auch bei
267    einem Tippfehler im Kommentar. Dafuer gibt es ``contract_version``.
268
269    ``dirty`` ist wichtiger, als es aussieht: Ein Lauf aus einem veraenderten
270    Arbeitsbaum laesst sich aus dem Commit allein **nicht** nachbauen. Wer
271    das spaeter wissen will, findet es hier statt es zu vermuten.
272
273    Drei Wege, in dieser Reihenfolge:
274
275    1. **Git.** Wo ein Repository liegt, ist es die beste Quelle - es kennt
276       auch den Arbeitsbaum und damit ``dirty``.
277    2. **``GIT_COMMIT`` aus der Umgebung.** Der Weg des Abbilds: ``.git/``
278       bleibt draussen, der Commit kommt beim Bau als Argument herein.
279       ``dirty`` ist dann ``False``, und das ist keine Annahme, sondern die
280       Lage - ein Abbild hat keinen Arbeitsbaum, der abweichen koennte. Dass
281       das Abbild aus einem sauberen Stand gebaut wird, sichert der Bau in CI
282       zu (FR-3), nicht dieses Modul. Verlangt wird eine volle SHA-1 aus
283       vierzig Hexstellen: Eine Kurzform oder ein Markenname ("v1.2") sieht
284       nachschlagbar aus und ist es nicht.
285    3. **Nichts von beidem** - installiertes Paket, fremdes Abbild, kein git
286       im Pfad: ``None``. Ein Lauf darf daran nie scheitern, und deshalb
287       steht hier keine einzige Zeile, die werfen kann.
288    """
289    wurzel = projektwurzel()
290
291    def git(*argumente: str) -> str | None:
292        if wurzel is None:
293            return None
294        try:
295            fertig = subprocess.run(
296                ["git", "-C", str(wurzel), *argumente],
297                capture_output=True, text=True, timeout=10,
298            )
299        except (OSError, subprocess.SubprocessError):
300            return None
301        return fertig.stdout.strip() if fertig.returncode == 0 else None
302
303    commit = git("rev-parse", "HEAD")
304    if commit is None:
305        mitgegeben = aus_der_umgebung()
306        if mitgegeben is None:
307            return {"git_commit": None, "git_dirty": None}
308        return {"git_commit": mitgegeben, "git_dirty": False}
309    geaendert = git("status", "--porcelain")
310    return {"git_commit": commit, "git_dirty": bool(geaendert)}

313def fingerabdruck(wert: Any) -> str:
314    """Ein Abdruck ueber die Eingaben - derselbe Stand, derselbe Abdruck.
315
316    Kanonisch heisst: sortierte Schluessel. Zwei Tabellen mit demselben
317    Abdruck ruhen auf denselben Eingaben, gleichgueltig in welcher
318    Reihenfolge sie gefunden wurden.
319    """
320    roh = json.dumps(wert, sort_keys=True, ensure_ascii=False)
321    return hashlib.sha256(roh.encode("utf-8")).hexdigest()

328def kennzeichen(wert: Any) -> Any:
329    """Nur die Teile einer Herkunft, die den Eingabestand kennzeichnen.
330
331    Pfade und Bauzeitpunkte fallen weg. Der Grund ist der gemeinsame
332    Speicher: Derselbe Stand liegt bei Christian unter ``/Users/...`` und bei
333    Artan anderswo, und ein zweiter Bau aus denselben Eingaben findet zu einer
334    anderen Uhrzeit statt. Beides darf den Abdruck nicht veraendern, sonst
335    traegt derselbe Stand zwei Abdruecke und die Zusage ist wertlos.
336
337    Was bleibt, ist das Kennzeichnende: Lauf-Kennungen, Pruefsummen und die
338    Abdruecke der Vorgaenger.
339    """
340    if isinstance(wert, dict):
341        return {k: kennzeichen(v) for k, v in wert.items() if k not in FLUECHTIG}
342    if isinstance(wert, list):
343        return [kennzeichen(v) for v in wert]
344    return wert

352def datei_hash(pfad: Path) -> str:
353    """SHA-256 einer Referenzdatei - fuer Crosswalks und Codelisten.
354
355    Ein Pfad sagt nur, *wo* etwas lag. Wer eine Zahl erklaeren will, braucht
356    aber, *was* dort stand: Die Crosswalks werden aus amtlichen PDFs erzeugt
357    und koennen sich aendern, ohne dass der Pfad sich aendert.
358    """
359    h = hashlib.sha256()
360    with pfad.open("rb") as datei:
361        for block in iter(lambda: datei.read(1 << 20), b""):
362            h.update(block)
363    return h.hexdigest()

366def referenz(pfad: Path, manifest: dict[str, Any]) -> dict[str, Any]:
367    """Wie eine abgeleitete Tabelle genannt wird, wenn eine andere auf ihr ruht.
368
369    **Ein Pfad ist keine Version.** ``data/silver/dataset=crime_offense/
370    part-0001.parquet`` zeigt auf das, was gerade dort liegt; wird Silver neu
371    gebaut, zeigt derselbe Satz auf etwas anderes, und nichts verraet es.
372    Deshalb nennt eine Referenz auch **wann** jener Stand gebaut wurde, auf
373    **welchen Eingaben** er ruhte (``input_fingerprint``) und - woertlich -
374    dessen eigene Herkunft. Damit ist die Kette im Manifest selbst
375    verschachtelt: Gold nennt Silver, Silver nennt die Bronze-Laeufe.
376
377    Das ersetzt keine Historisierung der Dateien. Es macht die Frage
378    beantwortbar, aus welchen Eingaben eine Zahl entstanden ist - und das ist
379    die Frage, die in einer Abgabe gestellt wird.
380    """
381    eintrag: dict[str, Any] = {"path": str(pfad)}
382    for schluessel in ("built_at_utc", "input_fingerprint"):
383        if manifest.get(schluessel):
384            eintrag[schluessel] = manifest[schluessel]
385    if manifest.get("derived_from") is not None:
386        eintrag["derived_from"] = manifest["derived_from"]
387    return eintrag

390def referenzdatei(pfad: Path) -> dict[str, Any]:
391    """Eine versionierte Referenzdatei mit ihrer Pruefsumme."""
392    return {"path": str(pfad), "sha256": datei_hash(pfad)}

395def versteckt(pfad: Path) -> bool:
396    """Ein ``.part``- oder ``.partial``-Verzeichnis ist ein Lauf, der noch nicht gilt.
397
398    ``.`` und ``..`` zaehlen nicht - sonst waere unter ``--data-root ../data``
399    jeder Lauf versteckt, und der Leser meldete stumm: nichts da.
400    """
401    return any(teil.startswith(".") and teil not in (".", "..") for teil in pfad.parts)

404def read_manifest(
405    pfad: Path,
406    *,
407    streng: bool = True,
408    fehler: type[Exception] = ManifestFehler,
409) -> dict[str, Any] | None:
410    """Liest ein ``manifest.json``. Kaputt: werfen (streng) oder warnen und ``None``."""
411    try:
412        return json.loads(pfad.read_text(encoding="utf-8"))
413    except (OSError, json.JSONDecodeError) as error:
414        if streng:
415            raise fehler(f"Invalid manifest: {pfad}") from error
416        LOG.warning("Manifest nicht lesbar, uebersprungen: %s", pfad)
417        return None

420def fertige_laeufe(
421    wurzel: Path,
422    muster: str = f"**/run_*/{MANIFEST}",
423    *,
424    streng: bool = True,
425    fehler: type[Exception] = ManifestFehler,
426    status: frozenset[str] = FERTIG,
427) -> list[Lauf]:
428    """Alle fertigen Laeufe unter ``wurzel``, nach Pfad sortiert.
429
430    Nach Pfad sortiert heisst bei ``run_<UTC-Zeitstempel>``: der letzte ist der
431    juengste. Versteckte Verzeichnisse zaehlen nie. Ein Lauf, dessen Manifest
432    nicht ``fertig`` sagt, wird mit Warnung uebersprungen - er liegt da, gilt
433    aber nicht.
434    """
435    if not wurzel.exists():
436        return []
437    laeufe: list[Lauf] = []
438    for pfad in sorted(wurzel.glob(muster)):
439        if versteckt(pfad):
440            continue
441        manifest = read_manifest(pfad, streng=streng, fehler=fehler)
442        if manifest is None:
443            continue
444        if str(manifest.get("status", "")).lower() not in status:
445            LOG.warning("Lauf uebersprungen, nicht fertig: %s", pfad.parent)
446            continue
447        laeufe.append(Lauf(pfad.parent, manifest))
448    return laeufe

451def tabellen(
452    data_root: Path,
453    schichten: tuple[str, ...] = ("silver", "gold"),
454    *,
455    fehler: type[Exception] = ManifestFehler,
456) -> list[Tabelle]:
457    """Jede gebaute Tabelle unter den Schichten, nach Schicht und Name sortiert.
458
459    Gesucht wird ``dataset=<name>/**/manifest.json``; liegt eine Tabelle
460    unter einer ``vintage=``, findet der Glob sie trotzdem.
461    """
462    gefunden: list[Tabelle] = []

353def datei_hash(pfad: Path) -> str:
354    """SHA-256 einer Referenzdatei - fuer Crosswalks und Codelisten.
355
356    Ein Pfad sagt nur, *wo* etwas lag. Wer eine Zahl erklaeren will, braucht
357    aber, *was* dort stand: Die Crosswalks werden aus amtlichen PDFs erzeugt
358    und koennen sich aendern, ohne dass der Pfad sich aendert.
359    """
360    h = hashlib.sha256()
361    with pfad.open("rb") as datei:
362        for block in iter(lambda: datei.read(1 << 20), b""):
363            h.update(block)
364    return h.hexdigest()

def fertige_laeufe( wurzel: pathlib._local.Path, muster: str = '**/run_*/manifest.json', *, streng: bool = True, fehler: type[Exception] = <class 'ManifestFehler'>, status: frozenset[str] = frozenset({'success', 'complete'})) -> list[Lauf]: 
421def fertige_laeufe(
422    wurzel: Path,
423    muster: str = f"**/run_*/{MANIFEST}",
424    *,
425    streng: bool = True,
426    fehler: type[Exception] = ManifestFehler,
427    status: frozenset[str] = FERTIG,
428) -> list[Lauf]:
429    """Alle fertigen Laeufe unter ``wurzel``, nach Pfad sortiert.
430
431    Nach Pfad sortiert heisst bei ``run_<UTC-Zeitstempel>``: der letzte ist der
432    juengste. Versteckte Verzeichnisse zaehlen nie. Ein Lauf, dessen Manifest

436    if not wurzel.exists():

447            continue
448        laeufe.append(Lauf(pfad.parent, manifest))
