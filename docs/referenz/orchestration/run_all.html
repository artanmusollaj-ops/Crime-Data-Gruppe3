orchestration.run_all

Faehrt die ganze Strecke in der richtigen Reihenfolge.

python -m orchestration.run_all                  # alles, inklusive Ingestion
python -m orchestration.run_all --ohne-ingestion # nur neu ableiten
python -m orchestration.run_all --bis silver     # bis zu einer Stufe
python -m orchestration.run_all --trocken        # nur zeigen, was liefe
python -m orchestration.run_all --jahre 2021-2026 --bis silver

--jahre nimmt einen Jahrgang, einen Bereich oder eine Liste; Vorgabe ist

  1. Die Kriminalquellen laufen je Jahrgang, die Census-Stufen je Vintage, alles andere einmal. Ab 2025 bleibt es beim 2024er Vintage - ein neueres gibt es nicht. Mehrere Vintages und Gold im Lauf lehnt der Controller ab, weil build_gold noch ein einzelnes --vintage nimmt.

Am Ende steht data/pipeline_run.json: welche Stufen liefen, wie lange, auf welchen Bronze-Laeufen das Ergebnis ruht, und ein Fingerabdruck darueber. Zwei Laeufe auf denselben Eingaben tragen denselben Fingerabdruck - damit laesst sich eine Zahl einem Stand zuordnen, statt ihn zu vermuten.

Warum die Stufen als Unterprozesse laufen: Ihre Kommandozeile ist die Schnittstelle, und sie ist getestet. Sie zu importieren und die main zu rufen waere ein zweiter Weg in denselben Code - und der zweite Weg ist der, der irgendwann anders funktioniert als der erste.

 51class Stufe(NamedTuple):
 52    """Ein Aufruf, der genau eine Sache tut."""
 53
 54    gruppe: str          # ingestion | silver | gold | serving
 55    name: str
 56    modul: str
 57    argumente: tuple[str, ...] = ()
 58    # Welchen Bronze-Bestand diese Stufe fuellt, so wie ``aktualitaet`` ihn
 59    # benennt. Nur Ingestion-Stufen haben einen. Damit ist die Liste der
 60    # *erwarteten* Quellen abgeleitet statt gepflegt - und eine Quelle, die
 61    # gar nicht da ist, faellt auf. Vorher wurde nur geprueft, was schon
 62    # existierte: Ein leerer Bestand galt als frisch.
 63    quelle: str = ""
 64    # Worueber diese Stufe sich wiederholt, wenn mehrere Jahrgaenge laufen:
 65    # "jahr" (die Kriminalquellen), "vintage" (Census und seine Silver-Tabellen),
 66    # "alle" (einmal, bekommt aber alle Vintages als Liste - so macht es Gold)
 67    # oder "" (einmal, ohne Jahresangabe). ``flagge`` ist die Option, mit der
 68    # die Stufe die Zahl annimmt - sie heisst nicht ueberall gleich.
 69    je: str = ""
 70    flagge: str = ""
 71
 72    def befehl(self, data_root: Path | None = None) -> list[str]:
 73        """Der Aufruf, mit dem diese Stufe laeuft.
 74
 75        ``--data-root`` wird **immer** mitgegeben, nicht nur wenn jemand es
 76        getippt hat. Bis zum 15.9.2026 wurde es gar nicht weitergereicht: Der
 77        Gesamtlauf inventarisierte und protokollierte im gewaehlten
 78        Verzeichnis, die dreizehn Unterprozesse arbeiteten im Standardordner.
 79        Eine externe Pruefung hat die abgefangenen Befehlszeilen gezeigt -
 80        keine einzige trug die Option.
 81
 82        Auch ohne ``--data-root`` steht hier jetzt der aufgeloeste Pfad. Das
 83        ist kein Mehraufwand und beseitigt eine zweite Fehlerquelle: Vater und
 84        Kind lesen dieselbe Umgebung, aber nicht mehr notwendigerweise
 85        gleich - etwa wenn ein Unterprozess eine andere ``.env`` faende.
 86        """
 87        wurzel = [] if data_root is None else ["--data-root", str(data_root)]
 88        return [sys.executable, "-m", self.modul, *self.argumente, *wurzel]

181def jahre_aus_text(text: str) -> tuple[int, ...]:
182    """``2024``, ``2021-2026`` oder ``2021,2023,2024`` - immer aufsteigend.
183
184    Doppelte Angaben fallen weg: Ein Jahrgang zweimal zu laden ergaebe zwei
185    Laeufe mit demselben Inhalt, und die Entdoppelung in Silver verbirgt das.
186    """
187    gefunden: set[int] = set()
188    for teil in text.split(","):
189        teil = teil.strip()
190        if not teil:
191            continue
192        if "-" in teil.lstrip("-"):
193            von_bis = teil.split("-", 1)
194            try:
195                von, bis = int(von_bis[0]), int(von_bis[1])
196            except ValueError:
197                raise ValueError(f"{teil!r} ist kein Jahresbereich") from None
198            if von > bis:
199                raise ValueError(f"{teil!r} laeuft rueckwaerts")
200            gefunden.update(range(von, bis + 1))
201        else:
202            try:
203                gefunden.add(int(teil))
204            except ValueError:
205                raise ValueError(f"{teil!r} ist kein Jahr") from None
206
207    if not gefunden:
208        raise ValueError("kein Jahr angegeben")
209    obergrenze = datetime.now(timezone.utc).year + 1
210    daneben = sorted(j for j in gefunden if not FRUEHESTES_JAHR <= j <= obergrenze)
211    if daneben:
212        raise ValueError(
213            f"{', '.join(str(j) for j in daneben)} liegt ausserhalb von "
214            f"{FRUEHESTES_JAHR} bis {obergrenze}"
215        )
216    return tuple(sorted(gefunden))

219def jahre_argument(text: str) -> tuple[int, ...]:
220    """``jahre_aus_text`` fuer argparse - mit erhaltener Begruendung.
221
222    Argparse faengt ``ValueError`` aus einem ``type=``-Aufruf und ersetzt die
223    Meldung durch *"invalid ... value"*. Der Benutzer erfuehre damit, dass
224    seine Angabe falsch ist, aber nicht warum - und das Warum ist der ganze
225    Sinn der Pruefung. ``ArgumentTypeError`` reicht argparse durch.
226    """
227    try:
228        return jahre_aus_text(text)
229    except ValueError as fehler:
230        raise argparse.ArgumentTypeError(str(fehler)) from None

233def entfalte(stufe: Stufe, jahre: Iterable[int]) -> list[Stufe]:
234    """Eine Stufe, so oft wie ihre Achse es verlangt.
235
236    Der Name bekommt die Zahl angehaengt, damit das Protokoll in
237    ``pipeline_run.json`` sagt, welcher Jahrgang wie lange brauchte, und ein
238    Abbruch die Stelle nennt statt nur die Stufe.
239    """
240    if not stufe.je:
241        return [stufe]
242    if stufe.je == "alle":
243        liste = ",".join(str(v) for v in vintages_fuer(jahre))
244        return [stufe._replace(argumente=(*stufe.argumente, stufe.flagge, liste))]
245    zahlen = (tuple(sorted(set(jahre))) if stufe.je == "jahr"
246              else vintages_fuer(jahre))
247    return [
248        stufe._replace(name=f"{stufe.name}_{z}",
249                       argumente=(*stufe.argumente, stufe.flagge, str(z)))
250        for z in zahlen
251    ]

259def bronze_laeufe(data_root: Path) -> dict[str, list[str]]:
260    """Jeder fertige Bronze-Lauf, nach Quelle geordnet.
261
262    Das ist die Antwort auf *"auf welchem Stand beruht diese Zahl?"*. Gelesen
263    werden die Manifeste selbst und nicht die Verzeichnisnamen: Ein Lauf, der
264    unterwegs abgebrochen ist, liegt zwar da, gilt aber nicht.
265    """
266    gefunden: dict[str, list[str]] = {}
267    for lauf in for_root(data_root).laeufe("bronze", "**/manifest.json"):
268        # Der erste Pfadteil unter bronze/ benennt die Quelle:
269        # city=chicago, dataset=tiger_tract, dataset=noaa_ghcnd ...
270        quelle = lauf.relativ.split("/")[1]
271        gefunden.setdefault(quelle, []).append(lauf.run_id)
272    return {k: sorted(set(v)) for k, v in sorted(gefunden.items())}

280def aktualitaet(data_root: Path) -> dict[str, str]:
281    """Wann jede Quelle zuletzt geladen wurde.
282
283    Keine Alarmierung - nur die Zahl, ohne die man sie nicht bauen kann. Wer
284    sehen will, ob eine Quelle veraltet, sieht hier nach.
285    """
286    juengste: dict[str, str] = {}
287    for lauf in for_root(data_root).laeufe("bronze", "**/manifest.json"):
288        quelle = lauf.relativ.split("/")[1]
289        wann = lauf.abgeschlossen_um
290        if wann and wann > juengste.get(quelle, ""):
291            juengste[quelle] = wann
292    return dict(sorted(juengste.items()))

295def veraltete_quellen(
296    data_root: Path, maximal_alter_tage: float, *, jetzt: datetime | None = None,
297    erwartet: Iterable[str] | None = None,
298) -> dict[str, float | None]:
299    """Quellen, die zu alt sind oder ganz fehlen - mit ihrem Alter in Tagen.
300
301    Bis hierher wurde die Aktualitaet nur **aufgezeichnet**: Das Gesamtmanifest
302    nannte je Quelle den juengsten Lauf, und niemand las es. Eine Zahl, die
303    niemand gegen etwas haelt, ist keine Kontrolle. Hier wird sie gegen eine
304    Schwelle gehalten.
305
306    Eine Quelle ohne einzigen fertigen Lauf steht mit ``None`` da - sie ist
307    nicht "frisch", sie ist nicht da. Der Docstring sagte das schon, der Code
308    tat es nicht: Geprueft wurde nur, was ``aktualitaet`` gefunden hatte, und
309    das sind genau die vorhandenen Quellen. Bei leerem Bestand kam ``{}``
310    heraus, also "alles in Ordnung". Eine externe Pruefung hat das am
311    15.9.2026 vorgerechnet.
312
313    ``erwartet`` kommt aus ``ERWARTETE_QUELLEN`` und damit aus den Stufen
314    selbst. Eine sechste Quelle taucht hier auf, sobald sie eine Stufe hat.
315    """
316    jetzt = jetzt or datetime.now(timezone.utc)
317    erwartet = ERWARTETE_QUELLEN if erwartet is None else erwartet
318    vorhanden = aktualitaet(data_root)
319    zu_alt: dict[str, float | None] = {}
320    for quelle in sorted(set(erwartet) | set(vorhanden)):
321        wann = vorhanden.get(quelle)
322        if wann is None:
323            zu_alt[quelle] = None
324            continue
325        stempel = datetime.fromisoformat(wann.replace("Z", "+00:00"))
326        if stempel.tzinfo is None:
327            stempel = stempel.replace(tzinfo=timezone.utc)
328        alter = (jetzt - stempel) / timedelta(days=1)
329        if alter > maximal_alter_tage:
330            zu_alt[quelle] = round(alter, 1)
331    return zu_alt

355def auswahl(ohne_ingestion: bool, bis: str | None,
356            jahre: Iterable[int] = VORGABE_JAHRE) -> list[Stufe]:
357    """Welche Stufen laufen, in welcher Reihenfolge, fuer welche Jahrgaenge.
358
359    Mit einem einzigen Jahrgang ist die Entfaltung die Identitaet: Es kommen
360    genau die vierzehn Stufen heraus, die ``STUFEN`` nennt. ``STUFEN``
361    beschreibt die **Form** der Strecke - daraus entstehen das Architekturbild
362    und die Referenz-Startseite, und die zaehlen vierzehn. Wie oft eine Stufe
363    laeuft, ist dagegen eine Eigenschaft des Laufs und steht hier.
364    """
365    stufen = [s for s in STUFEN
366              if not (ohne_ingestion and s.gruppe == "ingestion")]
367    if bis:
368        grenze = GRUPPEN.index(bis)
369        stufen = [s for s in stufen if GRUPPEN.index(s.gruppe) <= grenze]
370    return [entfaltet for s in stufen for entfaltet in entfalte(s, jahre)]

373def fahre(stufen: list[Stufe], projekt_root: Path,
374          data_root: Path | None = None, *,
375          behalte_lokal: bool = False) -> list[dict]:
376    """Eine Stufe nach der anderen. Beim ersten Fehler ist Schluss.
377
378    Weiterzulaufen waere schlimmer als abzubrechen: Die naechste Stufe baute
379    auf einem halben Stand und meldete Erfolg.
380
381    **``behalte_lokal`` muss ueber die Umgebung gehen und nicht im Prozess.**
382    Jede Stufe ist ein eigener Prozess (``sys.executable -m ...``), und was
383    hier an einer ``Config`` gesetzt wuerde, saehe keine von ihnen. Gesetzt
384    wird es, wenn ein Release folgt: Dann brauchen die Stufen ihre lokalen
385    Arbeitskopien noch, weil ``storage.release.sammle`` das Dateisystem liest.
386    Am 16.10.2026 fehlten dem Release sieben Gold-Tabellen bei einer gruenen
387    Strecke, weil jede Stufe ihre Kopie sofort entfernt hatte.
388    """
389    umgebung = None
390    if behalte_lokal:
391        umgebung = dict(os.environ, STORAGE_KEEP_LOCAL="1")
392    protokoll: list[dict] = []
393    for i, stufe in enumerate(stufen, 1):
394        LOG.info("[%d/%d] %s · %s", i, len(stufen), stufe.gruppe, stufe.name)
395        befehl = stufe.befehl(data_root)
396        start = time.perf_counter()
397        fertig = subprocess.run(befehl, cwd=projekt_root, env=umgebung)
398        dauer = round(time.perf_counter() - start, 1)
399        protokoll.append({
400            "gruppe": stufe.gruppe,
401            "name": stufe.name,
402            "befehl": " ".join(befehl[1:]),
403            "sekunden": dauer,
404            "exit": fertig.returncode,
405        })
406        if fertig.returncode != 0:
407            LOG.error(
408                "%s · %s ist mit %d gescheitert. Abgebrochen - jede weitere "
409                "Stufe baute sonst auf einem halben Stand.",
410                stufe.gruppe, stufe.name, fertig.returncode,
411            )
412            break
413        LOG.info("      fertig in %.1f s", dauer)
414    return protokoll

429         ohne_ingestion: bool = False, bis: str | None = None,
430         maximal_alter_tage: float | None = None,
431         release: bool | None = None, holen: bool = True,
432         jahre: Iterable[int] = VORGABE_JAHRE) -> dict:
433    """Die ganze Strecke - und am Ende, wenn alles gruen ist, ein Release.
434
435    ``release``: ``None`` heisst *wenn die Ablage publiziert* (hybrid, s3),
436    ``True`` erzwingt eines auch lokal, ``False`` unterlaesst es. Ein Release
437    entsteht nur nach einem vollstaendigen, gruenen Lauf bis einschliesslich
438    Serving - ein halber Stand bekommt keine Kennung. Scheitert das Release,
439    ist der Lauf gescheitert: Ein publizierender Modus, der nicht publiziert,
440    hat sein Versprechen nicht gehalten.
441
442    ``holen``: Im Hybridmodus werden zuerst alle Raw- und Bronze-Laeufe
443    geholt, die oben liegen und lokal fehlen - jeder Rechner soll den ganzen
444    Bestand haben, und Laeufe sind unveraenderlich, eine Kopie kann nicht
445    veralten. Scheitert das Holen, laeuft nichts weiter: Silver auf einem
446    halben Bronze waere genau der Stand, den niemand erklaeren kann. Im
447    ``s3``-Modus wird **nicht** geholt: Er ist als *ohne lokalen Bestand*
448    definiert, und ein Lauf, der ihn fuellte, widerspraeche seiner eigenen
449    Definition - dort liest Silver Bronze direkt von S3. Von Hand geht es
450    trotzdem (``python -m storage holen --wirklich``).
451    """
452    jahre = tuple(sorted(set(jahre)))
453    stufen = auswahl(ohne_ingestion, bis, jahre)
454    begonnen = datetime.now(timezone.utc)
455    zu_alt: dict[str, float | None] = {}
456
457    geholt: list[str] = []
458    holen_gescheitert: str | None = None
459    ablage = for_root(data_root)
460    if holen and ablage.backend == "hybrid":
461        try:
462            geholt = ablage.hole_fehlende_laeufe(("raw", "bronze"))
463        except StorageError as fehler:
464            holen_gescheitert = str(fehler)
465            LOG.error("Laeufe nicht geholt: %s. Nichts gebaut.", fehler)
466
467    # Ohne Ingestion werden die Daten nicht frischer. Sind sie schon zu alt,
468    # lohnt sich keine Stufe - und ein Gold auf veraltetem Bronze waere genau
469    # die Zahl, die dann auf einer Folie landet.
470    if maximal_alter_tage is not None and ohne_ingestion:
471        zu_alt = veraltete_quellen(data_root, maximal_alter_tage)
472        for quelle, tage in zu_alt.items():
473            LOG.error("%s. Nichts gebaut.",
474                      alterssatz(quelle, tage, maximal_alter_tage))
475
476    # Mit Ingestion in zwei Schritten: erst laden, dann pruefen, dann ableiten.
477    #
478    # Bis zum 15.9.2026 lief die Pruefung nach **allen** dreizehn Stufen. Der
479    # Lauf endete dann zwar mit "failed", aber Gold und Serving waren gebaut -
480    # aus Daten, die der Lauf selbst als zu alt erkannt hatte. Eine externe
481    # Pruefung hat genau das vorgefuehrt. Eine Kontrolle, die erst nach der
482    # Veroeffentlichung greift, ist ein Protokoll, keine Kontrolle.
483    geladen = [s for s in stufen if s.gruppe == "ingestion"]
484    abgeleitet = [s for s in stufen if s.gruppe != "ingestion"]
485
486    # Folgt ein Release, brauchen die abgeleiteten Stufen ihre lokalen
487    # Arbeitskopien noch: ``storage.release.sammle`` liest das Dateisystem.
488    # Nur sie - die Ingestion publiziert Laeufe, und die sollen weiterhin
489    # sofort weg (``Storage._lokal_entfernen_falls_s3``).
490    folgt_release = bis is None and (
491        release is True or (release is None and ablage.config.publiziert))
492    behalte_lokal = folgt_release and ablage.backend == "s3"
493
494    protokoll: list[dict] = []
495    if not zu_alt and holen_gescheitert is None:
496        protokoll = fahre(geladen, projekt_root, data_root)
497        ingestion_ok = (all(s["exit"] == 0 for s in protokoll)
498                        and len(protokoll) == len(geladen))
499
500        if maximal_alter_tage is not None and not ohne_ingestion and ingestion_ok:
501            zu_alt = veraltete_quellen(data_root, maximal_alter_tage)
502            for quelle, tage in zu_alt.items():
503                LOG.error("%s. Nichts abgeleitet.",
504                          alterssatz(quelle, tage, maximal_alter_tage))
505
506        if ingestion_ok and not zu_alt:
507            protokoll += fahre(abgeleitet, projekt_root, data_root,
508                               behalte_lokal=behalte_lokal)
509
510    gelaufen = all(s["exit"] == 0 for s in protokoll) and len(protokoll) == len(stufen)
511
512    geschafft = gelaufen and not zu_alt and holen_gescheitert is None
513
514    freigabe: dict | None = None
515    if geschafft and folgt_release:
516        from orchestration import release as release_modul
517        try:
518            freigabe = release_modul.bilde_und_publiziere(
519                data_root, ablage, jahre)
520            LOG.info("Release %s: %d Dateien%s", freigabe["release_id"],
521                     freigabe["files"],
522                     ", publiziert" if freigabe["published"] else ", nur lokal")
523        except StorageError as fehler:
524            LOG.error("Release gescheitert: %s", fehler)
525            freigabe = {"status": "failed", "error": str(fehler)}
526            geschafft = False
527
528    # Jetzt, und nicht in den Stufen: Was ``behalte_lokal`` aufgeschoben hat,
529    # geht hier weg - aber nur, was oben wirklich liegt
530    # (``Storage.arbeitskopien_entfernen`` fragt je Tabelle nach).
531    #
532    # **Auch nach einem gescheiterten Release.** Dann ist der lokale Stand
533    # kein Gewinn: Er ist oben schon vollstaendig, und ein naechster Lauf
534    # baut ihn neu. Ihn liegen zu lassen hiesse, dass ein Modus, der "ohne
535    # lokalen Bestand" heisst, nach jedem Fehlschlag einen behaelt.
536    if behalte_lokal:
537        weg = ablage.arbeitskopien_entfernen()
538        if weg:
539            LOG.info("%d lokale Arbeitskopie(n) nach dem Release entfernt",
540                     len(weg))
541
542    # Der Bestand fuer das Manifest liest im Hybridmodus auch S3. Faellt die
543    # Ablage aus, ist das kein Grund fuer einen Traceback: Der Lauf ist dann
544    # ohnehin gescheitert, und das Protokoll soll trotzdem geschrieben werden -
545    # mit dem, was lokal sichtbar ist, und mit dem Grund. Am 17.9.2026 hat
546    # genau hier ein Netzausfall sechzig Zeilen botocore-Stapel gedruckt,
547    # obwohl die Zeile darueber schon "Nichts gebaut" gemeldet hatte.
548    bestand_fehler: str | None = None
549    try:
550        laeufe = bronze_laeufe(data_root)
551        frische = aktualitaet(data_root)
552    except StorageError as fehler:
553        bestand_fehler = str(fehler)
554        LOG.error("Bestand nicht aufnehmbar: %s", fehler)
555        laeufe, frische = {}, {}
556        geschafft = False
557
558    manifest = {
559        "status": "complete" if geschafft else "failed",
560        "years": list(jahre),
561        "vintages": list(vintages_fuer(jahre)),
562        "fetched_runs": geholt,
563        "fetch_error": holen_gescheitert,
564        "inventory_error": bestand_fehler,
565        "release": freigabe,
566        "started_at_utc": begonnen.isoformat(),
567        "finished_at_utc": datetime.now(timezone.utc).isoformat(),
568        "stages": protokoll,
569        "input_bronze_runs": laeufe,
570        "input_fingerprint": fingerabdruck(laeufe),
571        "source_freshness": frische,
572        "freshness_check": {
573            "max_age_days": maximal_alter_tage,
574            "stale": zu_alt,
575        },
576        # Liest ebenfalls die Ablage; nach einem gescheiterten Lauf wird es
577        # ohnehin uebersprungen, und wenn nicht, gilt dasselbe wie oben.
578        "output_rows": zeilenzahlen(data_root) if geschafft else {},
579    }
580    schreibe_manifest(data_root, manifest)
581    return manifest

Die ganze Strecke - und am Ende, wenn alles gruen ist, ein Release.

release: None heisst wenn die Ablage publiziert (hybrid, s3), True erzwingt eines auch lokal, False unterlaesst es. Ein Release entsteht nur nach einem vollstaendigen, gruenen Lauf bis einschliesslich Serving - ein halber Stand bekommt keine Kennung. Scheitert das Release, ist der Lauf gescheitert: Ein publizierender Modus, der nicht publiziert, hat sein Versprechen nicht gehalten.

holen: Im Hybridmodus werden zuerst alle Raw- und Bronze-Laeufe geholt, die oben liegen und lokal fehlen - jeder Rechner soll den ganzen Bestand haben, und Laeufe sind unveraenderlich, eine Kopie kann nicht veralten. Scheitert das Holen, laeuft nichts weiter: Silver auf einem halben Bronze waere genau der Stand, den niemand erklaeren kann. Im s3-Modus wird nicht geholt: Er ist als ohne lokalen Bestand definiert, und ein Lauf, der ihn fuellte, widerspraeche seiner eigenen Definition - dort liest Silver Bronze direkt von S3. Von Hand geht es trotzdem (python -m storage holen --wirklich).
