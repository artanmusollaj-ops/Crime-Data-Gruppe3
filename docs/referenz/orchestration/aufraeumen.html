orchestration.aufraeumen

Was von Raw, Bronze und den Releases bleiben muss - und was weg darf.

python -m orchestration.aufraeumen              # zeigen, nichts loeschen
python -m orchestration.aufraeumen --loeschen   # entbehrliche Laeufe und
                                                # Releases loeschen, nur lokal
python -m orchestration.aufraeumen --loeschen --auch-fern
                                                # Releases auch auf SeaweedFS
python -m orchestration.aufraeumen --pinnen LN1 # den heutigen Stand festhalten

Raw und Bronze wachsen mit jedem Lauf, und bis hierher sagte nichts, wann etwas weg darf. Die Regel, je Quelle (city=chicago, dataset=noaa_ghcnd, ...), juengster Lauf zuerst:

  1. Gepinnt bleibt. Ein Lauf, auf den sich eine veroeffentlichte Zahl bezieht - eine Abgabe, eine Folie, ein Referenzstand -, steht in config/referenzstand.csv und wird nie aufgeraeumt. Diese Regel kam am 14.9.2026 dazu, weil die drei folgenden der Historisierung im Weg stehen: Regel 2 haelt nur, was das aktuelle Silver nennt - nach einem Neubau werden die Laeufe des vorigen Stands entbehrlich, und eine Zahl von letzter Woche waere nicht mehr nachzubauen.
  2. Der juengste Lauf und der davor bleiben. Der zweite ist der vorherige Schnappschuss - die einzige Moeglichkeit, eine Quelle gegen sich selbst zu pruefen. Detroit aendert abgeschlossene Faelle nachtraeglich (Notebook 13, Schritt 3), und das sieht man nur mit zwei Staenden.
  3. Von Silver genannt bleibt. Jedes Silver-Manifest nennt unter derived_from die Laeufe, auf denen es ruht. Sie zu loeschen hiesse, den Stand nicht mehr erklaeren zu koennen.
  4. Dessen Unterschied noch nicht gezogen ist, bleibt. Ein Vollschnappschuss traegt mehr als seinen Inhalt: Gegen seinen Vorgaenger gehalten sagt er, was die Quelle geaendert hat. Das zieht silver_pipeline.build_source_change heraus; bis dahin ist der Lauf unersetzlich. Danach genuegt die schmale Aenderungstabelle - 31,9 MB Schnappschuesse fuer 102 geaenderte Zeilen war das Verhaeltnis, das docs/intern/datenhistorie.md ausgerechnet hat. Diese Regel kam am 1.10.2026 dazu, zusammen mit der Tabelle. Sie steht zuletzt, weil sie die einzige ist, die von allein vergeht: Ein Lauf, den sie haelt, wird durch einen Befehl frei.
  5. Die Basis eines Delta-Laufs bleibt. Beide Staedte laden seit dem ersten vollen Schnappschuss nur Aenderungen - Chicago als mode: delta, Detroit seit dem 18.9.2026 als extraction_mode: DELTA; ohne den Schnappschuss darunter sind die Deltas wertlos. Ein Delta, das bleibt, haelt alles bis zum naechsten vollen Lauf fest.
  6. Alles andere ist entbehrlich. Gezeigt wird es immer; geloescht nur mit --loeschen, und dann Raw und Bronze zusammen - ein Bronze ohne sein Raw waere ein Ergebnis ohne Beweisstueck, ein Raw ohne Bronze ein Beweis ohne Ergebnis.

Ein Lauf gilt als Einheit: Ein ACS-Lauf liegt in zwei Verzeichnissen (state=17 und state=26), ein NOAA-Lauf in zwei Stationen. Sie kommen und gehen zusammen.

Was die Regel bewusst nicht tut: von allein laufen. data/ ist nicht versioniert, die Regel gilt je Rechner, und Loeschen ist ein Handgriff, den man sieht. In GitHub Actions laeuft jeder Datenlauf auf einer frischen Maschine und braucht sie nicht.

Releases, seit dem 4.10.2026. Daneben steht eine zweite Regel fuer releases/ - gepinnt plus die letzten acht, wie docs/intern/datenhistorie.md 5.5 sie entschieden hat. Sie ist bewusst schmaler als die Regel fuer Laeufe, denn ein Release traegt seine Herkunft selbst und nichts im Projekt sucht das neueste: Alles geht ueber releases/AKTUELL.json. Juengstes zuerst:

  1. Gepinnt bleibt - dasselbe Register config/referenzstand.csv und dieselbe Lesefunktion wie bei Laeufen. Eine Release-Kennung steht dort in der Spalte run_id; der Spaltenname wird dadurch unscharf, aber es gibt ein Register und nicht zwei.
  2. Das Release, auf das der Zeiger zeigt, bleibt - auch wenn es aus der Reihe fiele. ClickHouse, Elasticsearch, Kibana, serving.pruefe_stand und tools.build_einstieg loesen alle darueber auf; ein altes Release zu entfernen ist folgenlos, das aktuelle bricht fuenf Verbraucher auf einmal. Darum ist es eine eigene Regel und kein Nebeneffekt von "die letzten acht". Fehlt der Zeiger, sagt der Bericht das und laeuft weiter.
  3. Die letzten acht bleiben (RELEASES_N) - zwei Monate woechentlicher Releases. Gezaehlt wird wie bei Laeufen ueber die Reihenfolge, ein gepinntes oder aktuelles Release belegt also einen der acht Plaetze.
  4. Alles andere ist entbehrlich. Gezeigt wird es immer; geloescht lokal nur mit --loeschen und auf SeaweedFS erst mit --auch-fern dazu. Zwei Schalter, weil Laeufe lokal liegen und Releases oben als der gemeinsame Stand: Rund 900 Objekte aus dem geteilten Speicher zu entfernen soll zwei bewusste Entscheidungen kosten, nicht eine - dieselbe Haltung wie publish_table mit erzwingen=True.

Unveraenderlich bleiben Releases dabei: Geloescht wird ein ganzes Release oder keines, ein bestehendes wird nie ueberschrieben.

127class Bestand(NamedTuple):
128    """Ein Bronze-Lauf mit seinem Raw-Gegenstueck, ueber alle Partitionen."""
129
130    quelle: str
131    run_id: str
132    abgeschlossen: str
133    delta: bool
134    bronze: tuple[Path, ...]
135    raw: tuple[Path, ...]
136    zeilen: int
137    #: Die Ablagewurzel, unter der ``bronze`` und ``raw`` liegen. Sie steht
138    #: hier, damit ``bytes`` ueber ``storage`` zaehlen kann statt ueber offene
139    #: Pfade. **Pflicht**, ohne Vorgabewert: Mit ``None`` lag jedes
140    #: Verzeichnis ausserhalb der Wurzel, und ``bytes`` meldete 0 - ein
141    #: fehlender Wert haette sich als falsches Ergebnis gezeigt, nicht als
142    #: Fehler.
143    data_root: Path
144
145    @property
146    def ohne_raw(self) -> bool:
147        return not self.raw
148
149    @property
150    def bytes(self) -> int:
151        """Was das Loeschen dieses Laufs freigibt - Bronze und Raw zusammen.
152
153        Gezaehlt wird ueber ``Storage.bytes_unter``: Die Byte-Summe ueber ein
154        Praefix steht seit dem 4.10.2026 einmal im Projekt und nicht dreimal
155        ausgeschrieben. ``lokal=True``, weil Laeufe nur lokal aufgeraeumt
156        werden - im ``s3``-Modus laese die Ablage sonst gar nicht hier.
157
158        Die Entscheidung haengt an keiner dieser Zahlen: ``entscheide``
159        kennt nur Reihenfolge, Register und Manifeste. Diese Summe steht im
160        Bericht und sonst nirgends.
161
162        Ein Verzeichnis ausserhalb der Wurzel ist ein **Fehler**, kein
163        uebersprungener Posten: Stillschweigend weggelassen zeigte sich die
164        falsche Wurzel als zu kleine Zahl statt als Abbruch - genau die Falle,
165        die ``AGENTS.md`` unter dem fehlenden Census-Schluessel beschreibt.
166        """
167        ablage = for_root(self.data_root)
168        summe = 0
169        for verzeichnis in self.bronze + self.raw:
170            rel = ablage.relativ(verzeichnis)
171            if rel is None:
172                raise ValueError(
173                    f"{verzeichnis} liegt nicht unter der Ablagewurzel "
174                    f"{ablage.local_root} - die Belegung dieses Laufs liesse "
175                    f"sich nur zu klein angeben."
176                )
177            summe += ablage.bytes_unter(rel, lokal=True)
178        return summe

227def bestaende(data_root: Path) -> dict[str, list[Bestand]]:
228    """Alle fertigen Bronze-Laeufe, je Quelle, juengster zuerst.
229
230    Die Quelle ist der erste Pfadteil unter ``bronze/`` - dieselbe Einteilung
231    wie im Gesamtmanifest von ``run_all``. Das Raw-Gegenstueck ist das
232    Verzeichnis mit demselben relativen Pfad unter ``raw/``; fehlt es, ist der
233    Lauf ``ohne_raw``.
234    """
235    bronze = data_root / "bronze"
236    raw = data_root / "raw"
237    gruppen: dict[tuple[str, str], dict[str, Any]] = {}
238    for lauf in fertige_laeufe(bronze, streng=False):
239        relativ = lauf.verzeichnis.relative_to(bronze)
240        eintrag = gruppen.setdefault((relativ.parts[0], lauf.run_id), {
241            "abgeschlossen": "", "delta": ist_delta(lauf.manifest),
242            "bronze": [], "raw": [], "zeilen": 0,
243        })
244        eintrag["abgeschlossen"] = max(eintrag["abgeschlossen"], lauf.abgeschlossen_um)
245        eintrag["bronze"].append(lauf.verzeichnis)
246        if (raw / relativ).is_dir():
247            eintrag["raw"].append(raw / relativ)
248        eintrag["zeilen"] += lauf.zeilen
249
250    je_quelle: dict[str, list[Bestand]] = {}
251    for (quelle, run_id), e in gruppen.items():
252        je_quelle.setdefault(quelle, []).append(Bestand(
253            quelle, run_id, e["abgeschlossen"], e["delta"],
254            tuple(e["bronze"]), tuple(e["raw"]), e["zeilen"], data_root,
255        ))
256    for laeufe in je_quelle.values():
257        laeufe.sort(key=lambda b: (b.abgeschlossen, b.run_id), reverse=True)
258    return dict(sorted(je_quelle.items()))

261def genannt_in_silver(data_root: Path) -> set[str]:
262    """Jede Kennung, die ein Silver-Manifest unter ``derived_from`` nennt.
263
264    Die Form ist je Tabelle anders - ``crime_offense`` fuehrt Listen je Stadt,
265    die uebrigen eine Liste von Eintraegen mit ``run_id``. Gesammelt wird
266    deshalb jede Zeichenkette darin; verglichen wird gegen Kennung und
267    Verzeichnisnamen des Laufs, weil Chicago ``run_<Zeit>`` schreibt und
268    Detroit die nackte UUID.
269    """
270    kennungen: set[str] = set()
271
272    def sammle(wert: Any) -> None:
273        if isinstance(wert, str):
274            kennungen.add(wert)
275        elif isinstance(wert, dict):
276            for v in wert.values():
277                sammle(v)
278        elif isinstance(wert, list):
279            for v in wert:
280                sammle(v)
281
282    for tabelle in tabellen(data_root, ("silver",)):
283        sammle(tabelle.manifest.get("derived_from"))
284    return kennungen

306def gepinnte_laeufe(config_root: Path) -> dict[str, str]:
307    """Das Register: Lauf-Kennung -> Grund. Leer, wenn es die Datei nicht gibt.
308
309    Die Datei ist **versioniert**, anders als ``data/``: Ein Referenzstand ist
310    eine Verabredung des Teams, kein Zustand eines Rechners. Seit die Laeufe
311    auf SeaweedFS liegen, gelten die Kennungen fuer beide.
312    """
313    pfad = config_root / REFERENZSTAND_DATEI
314    if not pfad.exists():
315        return {}
316    with pfad.open(encoding="utf-8", newline="") as datei:
317        return {
318            zeile["run_id"]: zeile.get("grund", "")
319            for zeile in csv.DictReader(datei)
320            if zeile.get("run_id")
321        }

336def entscheide(laeufe: list[Bestand], genannt: set[str],
337               gepinnt: dict[str, str] | None = None,
338               ungezogen: set[str] | None = None) -> list[Entscheid]:
339    """Die Regel, angewandt auf eine Quelle. ``laeufe`` juengster zuerst."""
340    gepinnt = gepinnt or {}
341    ungezogen = ungezogen or set()
342
343    def ist_gepinnt(b: Bestand) -> bool:
344        return b.run_id in gepinnt or any(v.name in gepinnt for v in b.bronze)
345
346    gruende: list[str | None] = []
347    for i, b in enumerate(laeufe):
348        if ist_gepinnt(b):
349            gruende.append(GEPINNT)
350        elif i == 0:
351            gruende.append(JUENGSTER)
352        elif i < SCHNAPPSCHUESSE:
353            gruende.append(VORHERIGER)
354        elif b.run_id in genannt or any(v.name in genannt for v in b.bronze):
355            gruende.append(GENANNT)
356        else:
357            gruende.append(None)
358
359    # Ein Delta, das bleibt, braucht alles Aeltere bis zum naechsten vollen
360    # Lauf. Ein Delta, das geht, braucht nichts mehr.
361    braucht_basis = False
362    for i, b in enumerate(laeufe):
363        if gruende[i] is None and braucht_basis:
364            gruende[i] = BASIS
365        if gruende[i] is not None:
366            braucht_basis = b.delta
367
368    # Zuletzt, und das ist Absicht: ``UNGEZOGEN`` ist der **schwaechste**
369    # Grund. Er geht weg, sobald jemand build_source_change laufen laesst;
370    # ``BASIS`` und die uebrigen sind strukturell. Stuende er weiter vorn,
371    # verdeckte eine voruebergehende Bedingung die dauerhafte, und der
372    # Bericht saehe nach "einmal ziehen, dann darf es weg" aus, wo in
373    # Wahrheit ein Delta darueber haengt.
374    for i, b in enumerate(laeufe):
375        if gruende[i] is None and (
376                b.run_id in ungezogen
377                or any(v.name in ungezogen for v in b.bronze)):
378            gruende[i] = UNGEZOGEN
379    return [Entscheid(b, g) for b, g in zip(laeufe, gruende)]

524def loesche_releases(entscheide: list[ReleaseEntscheid], storage: Storage, *,
525                     auch_fern: bool = False) -> Geraeumt:
526    """Loescht entbehrliche Releases: lokal immer, oben nur mit ``auch_fern``.
527
528    Je Release zuerst das lokale Verzeichnis, dann - wenn verlangt - alle
529    Objekte unter demselben Praefix auf SeaweedFS, ``release.json`` zuletzt.
530    Ein fehlgeschlagenes Loeschen bricht ab und laesst den Rest stehen;
531    ``releases/AKTUELL.json`` liegt ausserhalb jedes Release-Praefixes und
532    wird nie angefasst.
533

535    Release, das nur oben liegt, hat kein lokales Verzeichnis: Ohne
536    ``auch_fern`` passiert dafuer nichts, und der Bericht darf keine
537    freigegebenen Bytes behaupten.
538    """
539    lokal: list[ReleaseEntscheid] = []
540    oben: list[ReleaseEntscheid] = []
541    schluessel: list[str] = []
542    for e in entscheide:
543        if e.bleibt:
544            continue
545        rel = f"{release.RELEASES}/release={e.release_.release_id}"
546        verzeichnis = storage.local_path(rel)
547        if verzeichnis.is_dir():
548            shutil.rmtree(verzeichnis)
549            lokal.append(e)
550            LOG.info("geloescht: %s", verzeichnis)
551        if auch_fern:
552            weg = storage.entferne_oben(rel, zuletzt=release.RELEASE_MANIFEST)
553            if weg:
554                oben.append(e)
555                schluessel.extend(weg)
556    return Geraeumt(lokal, oben, schluessel)

578def loesche(entscheide: list[Entscheid], data_root: Path) -> list[Path]:
579    """Loescht, was entbehrlich ist - Raw und Bronze zusammen.
580
581    Leer gewordene Partitionsverzeichnisse (``ingest_date=...``) gehen mit;
582    die Schichtwurzeln ``raw/`` und ``bronze/`` bleiben.
583    """
584    geloescht: list[Path] = []
585    for e in entscheide:
586        if e.bleibt:
587            continue
588        for verzeichnis in e.bestand.bronze + e.bestand.raw:
589            shutil.rmtree(verzeichnis)
590            geloescht.append(verzeichnis)
591            LOG.info("geloescht: %s", verzeichnis)
592            schicht = data_root / verzeichnis.relative_to(data_root).parts[0]
593            eltern = verzeichnis.parent
594            while eltern != schicht and eltern.is_dir() and not any(eltern.iterdir()):
595                eltern.rmdir()
596                eltern = eltern.parent
597    return geloescht

337def entscheide(laeufe: list[Bestand], genannt: set[str],
338               gepinnt: dict[str, str] | None = None,
339               ungezogen: set[str] | None = None) -> list[Entscheid]:
340    """Die Regel, angewandt auf eine Quelle. ``laeufe`` juengster zuerst."""
341    gepinnt = gepinnt or {}
342    ungezogen = ungezogen or set()
343
344    def ist_gepinnt(b: Bestand) -> bool:
345        return b.run_id in gepinnt or any(v.name in gepinnt for v in b.bronze)
346
347    gruende: list[str | None] = []
348    for i, b in enumerate(laeufe):
349        if ist_gepinnt(b):
350            gruende.append(GEPINNT)
351        elif i == 0:
352            gruende.append(JUENGSTER)
353        elif i < SCHNAPPSCHUESSE:
354            gruende.append(VORHERIGER)
355        elif b.run_id in genannt or any(v.name in genannt for v in b.bronze):
356            gruende.append(GENANNT)
357        else:
358            gruende.append(None)
359
360    # Ein Delta, das bleibt, braucht alles Aeltere bis zum naechsten vollen
361    # Lauf. Ein Delta, das geht, braucht nichts mehr.
362    braucht_basis = False
363    for i, b in enumerate(laeufe):
364        if gruende[i] is None and braucht_basis:
365            gruende[i] = BASIS
366        if gruende[i] is not None:
367            braucht_basis = b.delta
368
369    # Zuletzt, und das ist Absicht: ``UNGEZOGEN`` ist der **schwaechste**
370    # Grund. Er geht weg, sobald jemand build_source_change laufen laesst;
371    # ``BASIS`` und die uebrigen sind strukturell. Stuende er weiter vorn,
372    # verdeckte eine voruebergehende Bedingung die dauerhafte, und der
373    # Bericht saehe nach "einmal ziehen, dann darf es weg" aus, wo in
374    # Wahrheit ein Delta darueber haengt.
375    for i, b in enumerate(laeufe):
376        if gruende[i] is None and (
377                b.run_id in ungezogen
378                or any(v.name in ungezogen for v in b.bronze)):
379            gruende[i] = UNGEZOGEN
380    return [Entscheid(b, g) for b, g in zip(laeufe, gruende)]
